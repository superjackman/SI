# 课文白话

读者是几乎没有编程和数学课背景的人。正文先给生活里的画面，再给名字。

## 顺序

1. 先写一件读者做过的事（拧旋钮、找纸条、问人、排队）。
2. 这件事情说完，再引出术语，术语紧挨着刚才的画面。
3. 句子短。一句里只放一个新东西。
4. 能用具体数字就不用“一些”“很多”。数字必须是这一页算得出来的。
5. 公式放在「用符号写下来」。程序写在每课最后的「写成程序」，给想看写法的人，不放在开篇。

## 开篇不要出现的词

这些词不能出现在「写成程序」之前的正文、题干、图注里：

if-else、函数调用、API、变量、循环、NumPy、JSON、Schema。

英文同样：`if-else`、`function call`、`API`、`variable`、`loop`、`NumPy`、`JSON`、`Schema`。

写成程序那一段里可以出现，因为那一段就是给会写程序的人看的。

## 界面

不写“本节你将学会”“先别看答案”这类教法说明。按钮用做事的话：检查、看解答、自动拧、开始训练。
