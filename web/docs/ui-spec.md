# 课文控件

一课里的按钮、填空、选择、解答和实验滑块用同一套尺寸。间距只用 8、12、16、24。

## 按钮

三种，高度都是 40px，圆角 8px，左右内边距 16px，最小宽度 72px。按钮上不放装饰图标。

| 级别 | 样子 | 用在 |
| --- | --- | --- |
| 主要 | 海军蓝底，字用 `--on-navy` | 检查、下一站 |
| 次要 | 透明底，海军蓝描边和字 | 看解答 / 收起解答、播放 / 暂停 / 重播 |
| 文字 | 无边框，链接色 | 课文里不用。复制链接用次要按钮 |

## 填空

一张卡片里只有一行操作：

输入框 `flex: 1` 在左，右边依次是次要的「看解答」和主要的「检查」，间距 8px，和输入框垂直居中。

宽度 ≥ 1024px 时这一行不换行。宽度 < 600px 时，两个按钮作为一组换到下一行，整组靠右。

## 选择

选项通栏、纵向排列。卡片底部一行靠右，只有次要的「看解答」。这一行没有「检查」。

## 解答和反馈

出现在操作行正下方，仍在同一张卡片里。

底用色板里的浅色：解答用 `--mark-bg`，答对用 `--good-bg`，答错用 `--bad-bg`。左侧 3px 实线，颜色分别是 `--navy`、`--good`、`--bad`。内边距 12px 16px。不要虚线框。正文用 `--ink`，对比度至少 7:1。

## 卡片

一道题一张卡片。卡片不再套卡片，不要双层边框。内边距 16px 20px，圆角 12px。题号和题干在最上面，然后是操作行，再是解答或反馈。卡片内部间距 12px，卡片之间 16px。

## 实验

一条控制：标签在左，滑块占满剩余宽度，数值在滑块右边，播放或重播在最右。同一行，间距 8px，垂直居中。
