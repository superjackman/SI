损失函数

均方误差、极大似然、交叉熵

▶ 打开互动版（能点图、做实验、做小测）

需要一个数字来衡量“模型错了多少”，越小越好。

模型每猜一次，都要先知道“这次错了多少”。没有这个数，它就不知道该往哪改。损失函数就是给每次猜测打的“罚分”，训练就是让罚分越来越小。

  • 想象一个天气预报员：他说“明天 90% 下雨”，结果是晴天，应该被罚得很重；如果他说“50% 下雨”，罚得就轻一些。说得越肯定、错得越离谱，罚得越狠。
  • 模型也一样：先给每个候选答案打一个分数，再把分数换成概率，最后只看它给正确答案多少概率：给得越少，罚分越高。
  • 回归（预测一个数）：误差平方取平均，即均方误差。
  • 模型怎么给出概率：最后一层先给每个候选打一个分数（logit），可正可负；softmax 把它们变成全为正、加起来 100% 的概率（KM04 卡）。
  • 分类（预测类别）：看模型给正确答案分配了多少概率，即极大似然；取负对数就是交叉熵。
  • 在“噪声服从高斯分布”的假设下做极大似然，得到的正好是均方误差，所以 MSE 不是凭空设定的。
  • 左：模型给 4 个候选字打的分数，可正可负。中：softmax 先取指数（全变成正数），再除以总和，得到加起来 100% 的概率。右：正确答案的概率越小，罚分 −ln p 越大。
  • 如果正确答案是“蓝”，罚分 = −ln 0.625 ≈ 0.47；概率越接近 100%，罚分越接近 0。
  • MSE：预测 2.5、5、7.5，真实 3、5、7，误差平方 0.25、0、0.25，平均约 0.167。
  • softmax（KM04 卡同一例）：蓝 / 绿 / 红 / 天 的分数 → 概率 。
  • 交叉熵（KM07 卡同一例）：本站模型开始时正确的字「蓝」只得 → L = ；训练 200 步后 → L 。越自信地答错，罚得越重。
  • softmax(xᵢ) = e^xᵢ ÷ Σ e^xⱼ = pᵢ
  • L = −ln p(正确答案)
  • MSE = (1/n) × Σ (y预测 − y真实)²
  • softmax(xᵢ) = e^xᵢ ÷ Σ e^xⱼ：先取指数变成正数，再除以总和
  • MSE = (1/n) × Σ (y预测 − y真实)²
  • 负对数似然 = − Σ log P(yi | xi; θ)（连乘会下溢，取对数变成求和）
  • H(p, q) = − Σ p(k) × log q(k)；p 为 one-hot 时就是 −log q(正确类)
  • KL(p‖q) = H(p, q) − H(p)：p 固定时，最小化交叉熵 = 最小化 KL = 极大似然
  • xᵢ：模型给第 i 个候选打的分数（logit）
  • pᵢ：softmax 之后的概率，全部加起来是 1
  • L：只看正确答案那一格的概率，取负对数，这就是交叉熵损失
  • MSE：预测一个数（回归）时用，差值平方再取平均

留下的问题 有了损失 L(θ)，下一步是找出让 L 最小的 θ。参数有成千上万个，该怎么找？
