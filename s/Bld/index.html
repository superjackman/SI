自己搭 Agent

零代码平台或写代码：搭的都是“模型想 → 跑工具 → 再想”的循环。

不会代码用平台拖，会代码用 SDK 写循环；步骤固定就用工作流。

为什么这样设计：懂了这个循环，看任何 Agent 产品都知道它在干什么。

▶ 打开互动版（能点图、做实验、做小测）

🧒 先用大白话说

📏 这里讲：搭 Agent 的两条路（零代码平台、写代码），每条路有哪些真实的平台和框架，最小的 Agent 循环长什么样，上线前怎么测。这里不讲：怎么训练模型、各平台的价格、海外服务怎么开通。

搭 Agent 像做一个会自己查资料的小助理：它想一想，需要就去查（用工具），查到再想，直到能回答你。

📑 这一站讲了什么

  • 🛠 自己搭一个 Agent：两条路
    每个 Agent 里面都是同一个小循环：模型想 → 要工具就跑工具 → 结果交回模型 → 再想，直到能回答。你可以用平台“拖”出这个循环，也可以自己写代码。
  • 🧩 路线一：零代码 / 低代码平台
    零代码平台像搭积木：选模型、写说明、加工具和资料，拼好就能发布，不用写一行代码。
  • ⌨️ 路线二：25 行代码的 Agent 循环
    写代码时，模型只会说“请帮我用这个工具”，真正去跑工具的是你的程序；跑完把结果交回去，它再想下一步。
  • ✅ 上线前：先给它“考试”
    上线前像考驾照：准备 10 道题反复考，限制最多走几步、最多花多少钱，并把每一步记下来。
  • ⚠️ 容易混淆：工作流 vs Agent
    工作流像公交车：路线固定、准时、便宜；Agent 像出租车：司机自己挑路，灵活，但可能绕路、更贵。
