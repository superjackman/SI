整条链可以收成一句话：用样本找函数，一路被问题逼到 Agent 与应用。

  • 金字塔回答「长什么样」；这条链回答「怎样被逼出来」。
  • 每一步底部都有验证；用掌握度而不是「翻过」当进度。
  • 用样本找函数 → 概率 → 损失 → 梯度下降 → 非线性 → 反向传播 → 训练工程 → 词向量与分词 → RNN/注意力 → Transformer → 预训练与采样 → 评估 → 后训练 → LoRA/量化 → 推理效率 → RAG → Agent → 安全 → 多模态 → 推理时计算 → 应用。
  • 学习原则：先用 Python + NumPy 从零实现，读懂再看框架。每次只验证一个想法，就像写单元测试。每一步页面底部都有一条“动手验证”。
  • 0→…→A 串成闭环；回顾 = 地图 + 下一步行动。
  • 从一条直线到能看图的助手，罚分往下走，旋钮跟着坡动，这一套没有换。
  • 学习原则：一次只验证一个想法
  • 回链路图或去金字塔
