Dify

开源：自托管的检索和智能体工作台。

许可是改过的 Apache 2.0，多租户要另拿商业许可

尚未实测

官网

适合

想在自己的机器上用 Docker 搭检索和智能体工作台，并且机器达到 README 写的至少 2 核、4 GiB 内存。

不适合

想用这份源码经营多租户（LICENSE 里一个租户对应一个 workspace）却没有书面授权，或者要去掉前端里的标志和版权信息。

最小的一步

README 写的新部署：在仓库里进入 docker，把 .env.example 复制成 .env，用 OpenSSL 生成令牌，安装 Docker，守护进程在跑，Docker Compose 为 v2.35.0 或更新。docker/README 接着写 docker compose up -d，然后打开 http://localhost/install 。自托管文档还写 macOS 上 Docker Desktop 的虚拟机至少 2 个虚拟 CPU 和 8 GiB 内存。

文档里的结果

docker/README 写的结果是浏览器打开 http://localhost/install 完成初始设置，再在 http://localhost 登录。默认 HTTP 端口是 80。本页没有启动过这些容器，所以不写登录之后的界面原文。

许可

仓库 LICENSE 自称为改过的 Apache 2.0。上面的多租户和前端标志是附加条件；其余权利与限制按 Apache 2.0。README 的 License 一节写：本仓库使用基于 Apache 2.0 并带附加条件的 Dify Open Source License。这不是“代码公开就可以无条件商用”。

部署要什么

README：CPU 至少 2 核，内存至少 4 GiB；Docker 守护进程在跑；Docker Compose v2.35.0 或更新；还要 OpenSSL。自托管文档把同样的 CPU 和内存再写了一遍。

文档里写过的失败

docker/README 的排障表有一行：Python sandbox 返回 operation not permitted。同一行写 Sandbox 0.2.15 在关闭网络时限制 epoll_pwait，ARM64 和 AMD64 都写了，并写运行时失败已在 ARM64 上复现。

同一件事，真实的差别

自己搭一个能检索资料的工作台

  1. 起步方式不同。Dify 的 README 把 Docker Compose 当作最容易的起步，并写 CPU 至少 2 核、内存至少 4 GiB。RAGFlow 的 README 在 Docker 一节写建议起步是 4 核、16 GB 内存、50 GB 磁盘，并检出标签 v1.0.0。Flowise 的 README 快速开始是 Node.js 20 或更新，执行 npx flowise start，打开 3000 端口；Docker 是另一条路。
    • https://github.com/langgenius/dify/blob/main/README.md
    • https://github.com/infiniflow/ragflow/blob/main/README.md
    • https://github.com/FlowiseAI/Flowise/blob/main/README.md
  2. 许可不同。Dify 的 LICENSE 在 Apache 2.0 上加了条件：未经书面授权不能用源码经营多租户，前端里的标志和版权信息不能去掉。RAGFlow 的 LICENSE 文件是 Apache 2.0 全文。Flowise 的 LICENSE.md 写 enterprise 目录是商业许可，目录以外是 Apache 2.0。代码能打开，不等于可以无条件商用。
    • https://github.com/langgenius/dify/blob/main/LICENSE
    • https://github.com/infiniflow/ragflow/blob/main/LICENSE
    • https://github.com/FlowiseAI/Flowise/blob/main/LICENSE.md
  3. 文档里的第一屏不同。Dify 的 docker/README 写打开 http://localhost/install 建立管理员。RAGFlow 的 README 写 healthz 返回 HTTP 200 之后在浏览器登录，再到模型页填写 LLM、嵌入和重排，包括 API key。Flowise 的 README 写启动后打开 http://localhost:3000。本页没有替你跑过这三个安装。
    • https://github.com/langgenius/dify/blob/main/docker/README.md
    • https://github.com/infiniflow/ragflow/blob/main/README.md
    • https://github.com/FlowiseAI/Flowise/blob/main/README.md
