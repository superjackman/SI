vLLM

在自己的机器上对外提供开源模型。

官网

适合

要在 Linux 上按快速开始把一个模型做成兼容 OpenAI 的服务。那一页的前提是 Linux，Python 3.11 到 3.14。NVIDIA 是安装区的第一个标签。

不适合

机器不是 Linux，又想走那一页的默认安装。快速开始写 macOS 要另用 vLLM-Metal，不是默认的 pip 路径。服务一次只挂一个模型。

最小的一步

快速开始的 NVIDIA 安装：uv venv --python 3.12 --seed，激活虚拟环境，uv pip install vllm --torch-backend=auto，再执行 vllm download-kernels。在线服务的命令是 vllm serve Qwen/Qwen2.5-1.5B-Instruct 。默认地址是 http://localhost:8000 。列出模型的例子是 curl http://localhost:8000/v1/models 。

文档里的结果

快速开始的补全例子向 http://localhost:8000/v1/completions 发送 model 为 Qwen/Qwen2.5-1.5B-Instruct、prompt 为 San Francisco is a、max_tokens 为 7、temperature 为 0。页面没有印出模型返回的那一句。本页没有发过这个请求。

部署要什么

快速开始：操作系统 Linux，Python 3.11 到 3.14。README 写支持 NVIDIA、AMD、Intel GPU 以及 x86/ARM/PowerPC CPU，还有 TPU 等插件。服务默认一次一个模型，地址可用 --host 和 --port 改。

文档里写过的失败

快速开始写：如果不执行 vllm download-kernels，vLLM 会在启动时下载并编译内核，在 Hopper 和更新的 GPU 上可能多花几分钟。另一条：默认会套用模型仓库里的 generation_config.json，采样默认值可能被模型作者的建议盖掉；不想这样要在启动时加上 --generation-config vllm 。

同一件事，真实的差别

在自己的电脑上跑模型

  1. 谁负责跑模型，文档写的不一样。Ollama 快速开始是命令 ollama run gemma4:e2b，并写这个模型下载约 7.2 GB，建议 8 GB 可用显存或 Mac 统一内存。LM Studio 文档写的是桌面程序，用 llama.cpp 跑 GGUF，Apple 芯片上还可以用 MLX。llama.cpp 的 README 快速开始是 llama cli 或 llama serve，例子模型是 ggml-org/Qwen3.5-0.8B-GGUF。vLLM 快速开始是在 Linux 上执行 vllm serve Qwen/Qwen2.5-1.5B-Instruct，默认 http://localhost:8000，一次挂一个模型。Open WebUI 的 README 写的是浏览器界面，去连接 Ollama 或兼容 OpenAI 的接口；镜像标签 :ollama 才带上 Ollama，:main 不带。
    • https://docs.ollama.com/quickstart
    • https://lmstudio.ai/docs/app
    • https://github.com/ggml-org/llama.cpp/blob/master/README.md
    • https://docs.vllm.ai/en/latest/getting_started/quickstart/
    • https://github.com/open-webui/open-webui/blob/main/README.md
  2. 许可不同。Ollama 和 llama.cpp 的 LICENSE 是 MIT。vLLM 的 LICENSE 是 Apache 2.0。Open WebUI 的 LICENSE 允许再分发，但限制去掉品牌：滚动 30 天内直接使用的人数超过 50 时，去掉品牌需要书面许可或企业许可。LM Studio 没有查到公开仓库的 LICENSE。2026-11-07 请求 https://api.github.com/repos/lmstudio-ai/lmstudio 得到 404。官网条款给的是个人和内部业务使用，并把软件和源码称为商业秘密。代码公开和可以商用不是一回事；LM Studio 这边源码也没有作为公开仓库给出。
    • https://github.com/ollama/ollama/blob/main/LICENSE
    • https://github.com/ggml-org/llama.cpp/blob/master/LICENSE
    • https://github.com/vllm-project/vllm/blob/main/LICENSE
    • https://github.com/open-webui/open-webui/blob/main/LICENSE
    • https://lmstudio.ai/terms
  3. 文档写的机器不同。Ollama 快速开始把 gemma4:e2b 和约 7.2 GB 下载、8 GB 显存写在一起，并写显存更少时会改用系统内存，回答可能更慢。LM Studio 系统要求页写 Mac 要 Apple 芯片和 macOS 14.0 或更新，建议 16GB 以上内存，Intel 芯片的 Mac 目前不支持；Windows 建议至少 16GB 内存和 4GB 独显显存。vLLM 快速开始的前提写的是 Linux 和 Python 3.11 到 3.14，并注明 macOS 要另看 vLLM-Metal，不是那一页的默认安装。Open WebUI 的 pip 安装写需要 Python 3.12。
    • https://docs.ollama.com/quickstart
    • https://lmstudio.ai/docs/app/system-requirements
    • https://docs.vllm.ai/en/latest/getting_started/quickstart/
    • https://github.com/open-webui/open-webui/blob/main/README.md
