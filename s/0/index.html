用样本找函数

参数化模型 + 监督学习

▶ 打开互动版（能点图、做实验、做小测）

要解决的问题 有些任务写不出规则：“这张图里是不是猫”“这句话接下来该说什么”。用 if-else 根本写不完。

为什么要关心

有些事写不出 if-else：「这是猫吗」「下一句说什么」。换个办法：先给一个能拧的旋钮，再用例子把旋钮拧对。

生活类比

  • 像调收音机：旋钮是参数，收听效果靠大量试听（样本）来调。
  • 目标不是背下样本，而是没听过的歌也能收清楚——这叫泛化。

核心思想

  • 不写规则，先给一个带“旋钮”（参数 θ）的函数族，再用大量“输入 → 正确答案”的样本把旋钮拧到合适的位置。这就是参数化模型 + 监督学习。
  • 目标是泛化：在没见过的新输入上也预测准确。
  • 大模型也是这个框架，只是 θ 有几十亿个数字。

看图在说什么

  • 输入 x → 带参数 θ 的函数 → 预测；用样本把 θ 拧到合适。

算一算

  • 样本 (1,3)、(2,5)、(3,7) → 人眼看出 y = 2x + 1。
  • 样本 (1, 3)、(2, 5)、(3, 7)：人眼能看出 y = 2x + 1，即 w = 2、b = 1。
  • 如果有 1 亿条样本、x 有 1000 维，就看不出来了，需要机器自己找。

公式

  • y预测 = f(x; θ)
  • θ 有时是两个数，有时是几十亿个
  • y预测 = f(x; θ)，θ 是全部参数
  • 最简单的线性模型：y预测 = w × x + b
  • x：输入
  • θ：可调参数
  • y预测：模型输出

留下的问题 文字和分类都要用到「可能性」。下一步先把概率说清楚，再谈损失。
