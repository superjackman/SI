后训练：SFT、对齐与推理

SFT、RLHF/DPO、推理型强化学习

▶ 打开互动版（能点图、做实验、做小测）

让模型听懂指令、回答有用、足够安全，并学会“想清楚再回答”。

基座只会续写。要让它听指令、更安全、还会「先想再答」——靠后训练。

  • SFT：看示范，学格式。
  • RLHF / DPO：人说哪个回答更好，模型往那边靠。
  • 推理强化学习：答案能自动判对错的题上，学会写长思维链。
  • SFT：用“指令 → 优质回答”的示范数据，按同样的下一个词元损失继续训练（通常只对回答部分算损失），学会对话格式和风格。
  • RLHF：人类比较两个回答哪个好，比自己写好回答容易。先用偏好对训练奖励模型，再用强化学习（如 PPO）最大化奖励，并加 KL 惩罚防止偏离原模型太远、钻奖励模型的空子。
  • DPO（Rafailov 等，2023）：带 KL 约束的目标有闭式最优解，于是可以绕过奖励模型和强化学习，直接用偏好对训练，更简单、更稳定。
  • 推理型模型（2024 年起的主流方向）：在答案能自动验证的任务上（数学有标准答案、代码能跑测试）用强化学习，奖励只看最终答案对不对，模型逐渐学会写很长的思维链：分解、尝试、检查、回溯。部分厂商细节没有公开；公开方法中，GRPO 最早在 DeepSeekMath（2024）中提出，DeepSeek-R1（2025）也用它训练推理。
  • 预训练基座 → SFT → 偏好对齐 →（可选）推理 RL。
  • 奖励分 r_A = 1.5、r_B = 0.5 → P(A>B)=P(A 优于 B) = σ(1.5 − 0.5) = σ(1.0) ≈ 0.73。
  • 同一问题“天空是什么颜色？”两个回答：A 讲清了原因，B 说“不知道，自己查”，标注者选 A。
  • 奖励模型打分 r_A = 1.5、r_B = 0.5，则 P(A 优于 B) = σ(1.5 − 0.5) = σ(1.0) ≈ 0.73，训练会继续拉大差距。
  • P(A>B)=σ(r_A−r_B)
  • DPO：直接用偏好对，绕过奖励模型
  • 奖励模型（Bradley-Terry）：P(A 优于 B) = σ(r_A − r_B)
  • RLHF 目标：奖励 r − β × KL(当前模型 ‖ 参考模型)
  • DPO：损失 = − log σ(β × [log(π(好)/π参考(好)) − log(π(差)/π参考(差))])
  • 流水线：预训练（知识）→ SFT（格式）→ 偏好对齐 / 强化学习（偏好与推理）
  • 格式、偏好、推理三阶段
