概率基础

分布、条件概率、均值方差、高斯

▶ 打开互动版（能点图、做实验、做小测）

语言模型要预测「下一个字」，就必须先会说「可能性」。

AI 每猜一个字，其实是在说「接下来每个字有多大可能」。概率就是给可能性打分的语言。

  • 掷骰子：六点朝上的可能性是 1/6。所有朝向加起来必须是 1——这叫分布。
  • 已知「今天是晴天」，再问「要不要带伞」——这叫条件概率：在已知信息下重新分配可能性。
  • 语言模型就是在算：已知前文，下一个词元分别有多大可能。
  • 分布：每个候选一个 0～1 的概率，全部加起来 = 1。
  • 条件概率 P(下一个字 | 前文)：已知前面的话，下一个字分别有多大可能。大模型做的就是这件事。
  • 均值是一堆数的中心，方差是散开程度。后面注意力里「除以 √d」就用到「方差相加」。
  • 高斯（正态）分布：中间高、两边低的钟形曲线。下一步会看到：假设噪声是高斯时，极大似然正好推出均方误差。
  • 左：4 个候选的分数；中：变成概率（加起来 100%）；右：正确答案概率越小，后面的罚分越大。
  • 同一组 softmax 数：2.0 / 1.0 / 0.1 / −0.5 → 62.5% / 23.0% / 9.4% / 5.1%。
  • 候选蓝 / 绿 / 红 / 天：概率 62.5% / 23.0% / 9.4% / 5.1%。
  • 前文「天空是」时，条件概率最高的是「蓝」。
  • P(下一个 | 前文)，所有候选加起来 = 1
  • μ = 平均；方差 = 散开程度
  • P(蓝 | 天空是) + P(绿 | 天空是) + … = 1
  • 均值 μ = (1/n) Σ xᵢ；方差 ≈ (1/n) Σ (xᵢ − μ)²
  • 条件概率：大模型每一步都在算的东西
  • 均值 / 方差：后面 √d 缩放要用

留下的问题 会说可能性了。下一步要用一个能计算的数字衡量「这次猜错了多少」。
