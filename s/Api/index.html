API 调模型

密钥、接口格式、怎么算钱。

API 就是让你的程序代替你去问模型：带上密钥，发到平台地址，按输入、输出的词元数付钱。

为什么这样设计：想把模型接进自己的网站、脚本或工具，就得走 API。

▶ 打开互动版（能点图、做实验、做小测）

🧒 先用大白话说

📏 这里讲：怎么用国内平台的 API 让程序调模型、密钥怎么保管、钱怎么算。这里不讲：怎么访问或注册境外平台。

API 像一个点菜窗口：你的程序把“菜单”（问题）递进去，厨房（平台上的模型）做好菜（回答）递出来，按份量（词元）记账。密钥就是你的会员卡，丢了别人就能刷你的钱。

📑 这一站讲了什么

  • 🧪 3D 点菜窗口
  • 🔌 API：让你的程序直接问模型
    在网页上和模型聊天，是“你”在问；用 API（应用程序接口），是“你写的程序”在问。程序发一段文字过去，平台上的模型算完把回复发回来，按用了多少“词元”记账。
  • 🏪 国内常见的模型平台
    国内不少平台都卖“按用量付费”的模型调用。下面的表只列官网写着的价格，价格会变，以官网为准。“¥/百万词元”就是每用一百万个词元付多少钱。
  • 🔑 密钥：像家门钥匙一样保管
    密钥像家门钥匙：放在兜里（环境变量），不要挂在门上（写进代码、放在网页里、发到群里）。给每个项目配一把，再设一个“每月最多花多少”。
  • 🔁 OpenAI 兼容格式：换个地址就能换平台
    很多平台都听得懂同一种“点菜格式”（OpenAI 兼容格式）。换平台时，只改三样：地址、密钥、模型名。问题放在 messages 里，按“谁说的”排好：system 是规矩…
  • 🚀 第一次调用：curl 和 Python
    第一次调用，就是在命令行里发一封固定格式的信。成功会收到回答和用量；收到 401 是密钥不对，402 一般是余额不够，429 是请求太快，等一下再试。
  • 💰 怎么算钱：词元 × 单价
    钱 = 你发过去的字数（输入词元）× 输入价 + 它写回来的字数（输出词元）× 输出价。输出更贵；同样的开头重复发，可能按更便宜的“缓存价”算。
  • ⚠️ 容易混淆：输入价 vs 输出价
    读（输入）比写（输出）便宜：读一页书很快，写一页要一个字一个字地想。所以同一个模型，输出价通常是输入价的好几倍。
  • ⚠️ 容易混淆：缓存命中 vs 没命中
    就像老师批改作业：前面和上次一模一样的部分已经看过，直接打勾，只按便宜价算；从第一个不一样的字开始，才按正常价算。
  • 🧪 费用计算器：一次多少钱、一个月多少钱 (动手实验)
