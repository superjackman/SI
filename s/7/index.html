RNN + 注意力

循环状态；注意力缓解瓶颈

▶ 打开互动版（能点图、做实验、做小测）

对变长序列建模，让同一个词的表示随上下文变化。

句子有长有短。一个词一个词往后传，开头会越来越淡，也没法一次看完整句。要让每一步都能回头看全部。

  • 只传一张小纸条，纸条装不下，前面的意思就丢了。
  • 回头看名牌：每次开口前扫一眼所有人，按对得上的程度来听。
  • RNN：维护一个“记忆”向量 h，逐个读入词更新它；同一组参数每步重复使用。
  • 问题：沿时间反向传播时梯度多次连乘，长依赖难学；h_t 要等 h_(t−1) 算完，无法并行。LSTM/GRU 用门控和以加法为主的细胞状态缓解（和残差思想类似），但没根治。
  • seq2seq 瓶颈：翻译时编码器把整句压进最后一个向量，句子一长信息就丢。
  • 注意力（Bahdanau、Cho、Bengio，2014 年提出，ICLR 2015 发表）：每生成一个词都回看编码器所有位置，打分、softmax 成权重、加权求和，得到这一步专属的上下文向量。
  • 纸条一步步往后传。回头看的时候，给每个词打分，再按分数把它们的内容混在一起。
  • 3 个源词分数 [2, 1, 0] → 三份份额 [0.665, 0.245, 0.090]。
  • 3 个源词打分 [2, 1, 0]：e² ≈ 7.389，e¹ ≈ 2.718，e⁰ = 1，总和 11.107。
  • 权重 ≈ [0.665, 0.245, 0.090]，模型主要在“看”第一个词。
  • RNN：输入 x = 1, 0, 0, 0 → h = 0.76 → 0.36 → 0.18 → 0.09，第一个词的影响每步约减半。
  • softmax：分数 2.0 / 1.0 / 0.1 / −0.5 → 62.5% / 23.0% / 9.4% / 5.1%。
  • aᵢ = softmax(eᵢ)；c = Σ aᵢ hᵢ
  • h_t = tanh(W × h_(t−1) + U × x_t + b)
  • 权重 a_i = e^(e_i) / Σ e^(e_j)；上下文 c = Σ a_i × h_i
  • 权重现算，不是固定参数

留下的问题 注意力很好用，但它还挂在必须一个词等一个词的记忆上。既然任意两个位置已经能直接说话，能不能拿掉排队，只留注意力？
