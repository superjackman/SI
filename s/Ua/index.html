跟它一起干

你在旁边看着，它一步步动手。

对话助手、编辑器里的编程 Agent、命令行 Agent、操作电脑的 Agent：你开口、你看着、关键步骤你点头。

为什么这样设计：目标还在变、需要你随时拍板的活，最适合“一起干”：错误在第一步就能被你拦下。

▶ 打开互动版（能点图、做实验、做小测）

🧒 先用大白话说

“一起干”就像你带着一个徒弟：你开口，你看着，它每做一步你都看得见，要紧的地方你点头它才做。四种用法里，它能碰的东西一个比一个多，所以越往后越要管好它的“钥匙”。

📑 这一站讲了什么

  • 跟它一起干：你在场，它动手
    这一类用法的共同点：你开口、你看着、关键步骤你点头。Agent 在你眼前一圈一圈地转，每一圈做了什么都看得见。
  • 💬 对话助手
    对话助手就是一问一答：在网页或 App 里聊天，它能上网查一查、读你发的文件，但碰不到你的电脑和账号，所以最安全。聊得太久它会忘掉前面的内容；重要的数字和结论要自己再查一遍。
  • 🧑‍💻 编辑器里的编程 Agent
    编辑器里的编程助手住在你写代码的软件里，能读整个项目。它可以帮你接着往下写、回答问题，也可以自己改好几个地方，最后把改动一条条摆出来，你决定收不收。改坏了还能退回去。
  • ⚠️ 容易混淆：对话助手 vs 编程 Agent
    对话助手像电话那头的老师傅：你问，他告诉你怎么改，动手的是你。编程 Agent 像请师傅上门：他自己打开你的项目、改文件、试一试能不能用，最后把改了哪些给你看，由你点头。
  • ⌨️ 命令行编程 Agent
    命令行里的编程助手几乎什么都能做，所以要像给孩子零花钱一样分档给权限：刚开始每一步都要问你；熟了以后改文件不用问、运行命令要问；全自动只在一台“坏了也没关系”的隔离机器上开。
  • 🖱️ 浏览器 / 电脑操作 Agent
    没有现成的接口时，就让助手像人一样用电脑：看一眼屏幕、点一下、打几个字、再看一眼。危险在于网页上可能藏着骗它的话（“忽略之前的指示……”），所以要在隔离的浏览器里用，付钱、发送…
  • 🧪 一次编程会话：看它一圈圈改代码 (动手实验)
  • 🧪 截图 → 动作：操作电脑的 Agent (动手实验)
