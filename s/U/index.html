怎么用 Agent

同一个 Agent，八种用法；差别只在四件事。

从“你怎么用它”的角度看 Agent：谁来发起、在哪里跑、能动什么、你要不要盯着。每种用法都能往下钻到原理那一侧。

为什么这样设计：先知道“能怎么用”，再看“为什么能这样用”，学原理时就有了挂钩。

▶ 打开互动版（能点图、做实验、做小测）

🧒 先用大白话说

Agent 就像一个能动手的助手，用法很多，但里面都是同一个东西。不同用法只差四件事：谁叫它开工、它在哪儿干活、它能碰什么、你要不要在旁边看着。

📑 这一站讲了什么

  • 🧪 3D 一起干 / 自己干
  • 同一个 Agent，为什么有这么多种用法？
    所有用法的底层都是同一个东西：Agent = 大模型 + 工具 + 循环。区别只在外面这一层的四件事：
  • 八种用法，一张表看懂
    把八种用法按这四件事排成一张表，像课程表一样一眼能对比：哪种只能说话，哪种能改文件，哪种你得盯着，哪种交出去就行。
  • 怎么选：先问任务四个问题
    挑用法前先问自己四个问题：要不要它动手？能不能检查做得对不对？是不是经常要做？做错了能不能撤回？撤不回的事（发出去、删掉、付钱），一定要留一步让人点头。
  • 🧪 帮我选用法：勾选任务特点，看推荐 (动手实验)
  • 🧠 底层逻辑：权限 × 监督
    给助手的钥匙越多（能做的事越多），就越要有人看着或者把它关在安全的小房间里。还有，小错会越积越多：每一步都有一点出错的机会，步数一多，全对的机会就小了很多，所以长任务中间要检查。
  • 🗂️ 具体产品去哪找
    想知道每种用法有哪些真实的产品、官网在哪，去“具体产品”那一站看。
