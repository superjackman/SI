大模型

大模型就是一台“猜下一个词”的机器。

大模型就是一台“猜下一个词”的机器：文字切成 token → 变成向量 → 几十层加工 → 给每个候选词打分 → 抽一个接上去，反复进行。

为什么这样设计：“猜下一个词”的题目能从任何文本里自动出，所以可以用海量数据来训练。

🧒 先用大白话说

大模型其实在玩词语接龙：你给它一个开头，它猜“下一个词最可能是什么”，接上去，再猜下一个……一个词一个词地把整段话写出来。下面的图就是它肚子里的流水线：文字从左边进去，右边出来的是“每个词有多大可能是下一个”。

📑 这一站讲了什么

  • 大模型整体：一场“猜下一个词”的接龙游戏
    在 Agent 眼里，大模型就是“读一段文字、续写一段文字”的黑盒。打开它：文字从左边进，经过一条流水线，右边吐出“下一个词的概率”。抽一个词接回句子末尾…
  • 🎲 动手玩：接龙游戏
    你来当裁判：模型给每个候选词打了分，按分数抽一个接上去，看句子怎么长出来（分数是编好的示例）。
  • 流水线每一站在干嘛（以“今天天气真”为例）
    流水线上每一站各干一件小事：先把句子切成小块，每块换成一个编号；每个编号查出一串代表意思的数字；再记上“排第几个”；然后经过几十层反复加工，让每个词都“读懂”整句话…
  • ⚠️ 容易混淆：词嵌入 vs 位置信息
    进模型前，每个词元带上两样东西：它是谁（词嵌入，查字典得到），和它排第几（位置信息）。同一个字放在不同位置，“是谁”不变，“排第几”变了。
  • 🧠 底层逻辑：这条流水线为什么这样设计、为什么有效
    为什么这样设计？最大的好处是：“猜下一个词”的练习题到处都是。任何一段文字，遮住后面一个词，就是一道自带答案的题，不用人来出题、改卷。为了猜得准，模型不得不学会语法…
  • ✂️ 分词器小实验
    模型不认识字，只认识编号。所以先把句子切成小块，像切蛋糕：常见的词整块切，少见的拆碎一点。在下面打几个字试试看。
  • ⚠️ 容易混淆：词元 vs 字和词
    模型读文字时，先用分词器把句子切成小块，这些小块叫词元。一块可能是一个字，也可能是半个词或一整个词，和我们平时说的“字”“词”不一样。
  • 🪟 上下文窗口：超出就“看不见”
    模型一次能看的字数有上限，像一扇窗户：话太长，最早的部分就挪出窗外，它就“看不见”了。拖动滑块改变窗户大小试试。
  • ⚠️ 容易混淆：参数量（7B）vs 上下文长度（128K）
    “7B”是模型脑子里有多少个数（70 亿个），“128K”是它一次能看多少个词元。一个是脑子多大，一个是桌子多大。
  • 🏋️ 训练流水线：一个大模型是怎么被“教”出来的
    大模型是分好几个阶段“上学”教出来的，像先上小学打基础、再学规矩、再参加考试练习。点图里的方块看每个阶段学什么。
  • ⚠️ 容易混淆：训练 vs 使用（推理）
    训练是上学：做题、对答案、改正，脑子里的数会变。使用是考试：只答题，不改脑子里的数。你和它聊天就是在“考试”。
  • 🧩 变体：MoE（专家混合）块
    MoE 就像一家医院有很多位专科医生，门口有个分诊台：每个词只被送去看其中一两位，不用所有医生都出马。医生总数多了，但每个词花的力气没多多少。
  • 🤔 推理模型：先想再答，用“推理时计算”换正确率
    有的模型会先打草稿再回答，就像做数学题先写步骤：慢一点、费字数，但多步的数学题、写程序、做计划会准很多。查个事实、改写句子这种简单事，直接答就够了。
  • 🫥 幻觉：为什么会一本正经地说错，以及怎么压住它
    “幻觉”就是模型一本正经地说错话。原因之一：只见过一两次的冷门事实本来就记不牢，它只好挑一个“听起来像”的；原因之二：很多考试答错和说“不知道”一样得 0 分，等于鼓励它瞎猜。…
  • 📎 上下文学习：在提示词里放几个例子，它就会了
    在问题前面放几个例子，模型就能照着做，像老师先做两道示范题。模型本身一点没变，例子只在这一次对话里起作用。
  • 🎯 怎么挑词、怎么打分：束搜索与困惑度
    每一步都挑最好的词，整句不一定最好，就像下棋只看眼前一步可能会输。束搜索同时留着几条候选句，最后挑整句最好的那条。困惑度是给模型的打分：它越能猜中真正的下一个词，这个数就越小。
  • ⚠️ 容易混淆：温度 vs top-p
    挑下一个词时有两个旋钮：温度决定“只爱第一名，还是谁都给机会”；top-p 决定“先把哪些词赶出候选名单”。
  • 🧪 自己打一句话，看它被切成 token (动手实验)
  • 🧪 BPE 分词：一步步合并出词表 (动手实验)
  • 🧪 接龙大师：你来选词，看温度 / top-k / top-p 怎么改概率 (动手实验)
  • 🧪 多想几遍再投票：推理时计算值不值 (动手实验)
  • 🧪 贪心 vs 束搜索：开局最好 ≠ 整句最好 (动手实验)
  • 🧪 困惑度：概率越准，数字越小 (动手实验)
