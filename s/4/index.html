反向传播

链式法则；ReLU、残差、归一化

▶ 打开互动版（能点图、做实验、做小测）

高效地求出所有参数的梯度。

前面那颗旋钮怎么拧？不能靠猜。先看最后的罚分是谁弄大的，再把这个原因从后往前传。

  • 像一排齿轮：最后一片转了多少，可以反推前面每一片该怎么调。
  • 从最后一层往前传，每颗旋钮都知道自己该拧多少。这件事可以自动做。
  • 路一长，前面就听不见。小于 0 的先当成 0，并且留一条把原来的数加回去的直路。
  • 网络是函数的嵌套 L = f3(f2(f1(x)))，链式法则把各层的局部导数连乘起来。
  • 反向传播：先前向算出每层的值，再从输出往回逐层传“上游梯度 × 本层局部导数”。中间结果复用，一次反向的代价和一次前向差不多（1986 年 Rumelhart、Hinton、Williams 让它广为人知），这就是框架里“自动求导”的本质。
  • 新问题梯度消失/爆炸：sigmoid 导数最大 0.25，10 层连乘 0.25^10 ≈ 0.00000095。对策：ReLU（正区间导数为 1）、残差（y = x + F(x)，总有一条导数为 1 的直通路，ResNet，He 等 2015）、归一化（LayerNorm 等）、按层宽缩放的初始化（参数不能全为 0）。
  • 先从前往后算出每层的数，再把坡从后往前传回来，就知道每颗旋钮该往哪拧。
  • dL/dx = 0.5 × 3 × 2 = 3。带上 ReLU 之后，坡还要再穿过那一层弯。
  • 链式法则：dL/dx = 0.5 × 3 × 2 = 3；下面换成带 ReLU 的小网络。
  • y = w2 × ReLU(w1 × x)，L = (y − t)²，取 x = 1、w1 = 2、w2 = 3、t = 5。
  • 前向：h = 2，y = 6，L = 1。反向：dL/dy = 2(6 − 5) = 2。
  • dL/dw2 = 2 × h = 4；dL/dh = 2 × w2 = 6，h > 0 所以 dh/dw1 = x = 1，得 dL/dw1 = 6。
  • dL/dx = dL/df × df/dx
  • 残差 y = x + F(x) → 总有一条导数为 1 的路
  • dL/dx = dL/df3 × df3/df2 × df2/df1 × df1/dx
  • 残差：y = x + F(x)，于是 dy/dx = 1 + dF/dx
  • 上游梯度
  • 本地导数
  • 传到更前

留下的问题 梯度能求了，但数据有上百万条时每一步都遍历全部数据太慢；不同参数需要的步长不一样；模型还可能把训练集“背下来”。
