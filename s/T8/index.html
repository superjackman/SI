🧒 先用大白话说

这是整个网站的一张大地图：从上到下大致是“用 AI 做事 → 模型 → 模型里的零件 → 看图听声 → 怎么练出来 → 用什么机器跑”。点任何一个方块看它是什么，还能跳到讲它的那一站。

📑 这一站讲了什么

  • 全景关系图：所有零件一张图
    从上到下大致是“应用 → 模型 → 内部零件 → 多模态 → 训练 → 算力”。连线 = “属于 / 被谁包含”（虚线是补充关系）。点任意节点打开它的详情…
  • 术语速查表
    这是一本小词典：所有零件按所在的站排好，每个配一句话。忘了某个词，就来这里查；点名字看详情，点“所在页”直接跳过去。
  • 🏁 我的学习进度
    这里记着你走过哪些站、测验答对几题，像一张集章卡。它只存在这台设备的浏览器里，不会上传。
  • 🧪 全部动手实验
    全站所有可以自己动手玩的实验都在这里，每个写着在哪一站。点一个就过去。
