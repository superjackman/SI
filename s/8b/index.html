组装成 Transformer

多头、FFN、残差、归一化、位置

▶ 打开互动版（能点图、做实验、做小测）

把注意力做成能叠很多层、又稳又能分辨词序的完整模型。

注意力只是一个零件。真正的大模型像一栋楼：同一种“楼层”（解码块）叠几十层。每层做两件事：先交流（注意力），再各自消化（前馈网络）。

  • 像一个侦探小组开会：几个侦探各查一条线索（多头：一个查“它指谁”，一个看相邻的词，一个找原因）；开完会每人回到工位自己消化（前馈网络 FFN）。
  • 每次只在原稿上写批注，不重写原稿（残差）；开会前先把每个人的音量调到一样（归一化）；每个人还带着座位号，不然分不清谁先谁后（位置编码）。
  • 多头：维度切成 h 份各做注意力再拼起来，每个头可以学一种关系（例如指代、相邻、因果）。
  • 位置编码：注意力本身不管顺序；如今多用 RoPE（苏剑林等，2021，RoFormer），按位置旋转 q、k，使点积只取决于相对距离；演进：正弦（原论文）→ 可学习（GPT-1/2）→ RoPE（如今主流）。
  • FFN：每个位置独立的两层网络，中间维度常为模型维度的约 4 倍 常见值，各模型不同，激活演进：ReLU（原版）→ GELU（GPT）→ SwiGLU（如今常用）。
  • 残差 + 归一化让它能叠很多层；归一化演进：原版 Post-LN（本站图）→ GPT-2 起 Pre-LN → 新模型常用 RMSNorm。
  • 一个解码块：输入先归一化，多头注意力交流，结果加回输入；再归一化，FFN消化，再加回。同样的块叠 N 层，最后接输出头。位置在注意力里旋转 q、k（RoPE）。
  • 原论文的解码器叠了 N = 6 层；如今的大模型常叠几十层。
  • 原论文：模型维度 d = 512、h = 8 个头，每个头 512 ÷ 8 = 64 维。
  • 参数量粗算：每个解码块约 12 × d² 个参数（注意力 4 × d² + 前馈 8 × d²） 粗算，不含词向量表。
  • MultiHead(x) = Concat(head1, …, headh) × W_O
  • x = x + Attention(Norm(x))
  • x = x + FFN(Norm(x))
  • MultiHead(x) = Concat(head1, …, headh) × W_O
  • x = x + Attention(Norm(x))，x = x + FFN(Norm(x))
  • RMSNorm(x) = x / √(mean(x²) + ε) × g
  • 多头：维度切成 h 份，每份各做一次注意力，再拼回去
  • + 残差：结果加回输入，原稿不丢，梯度有直通路
  • Norm 归一化：把每个词的那串数拉回统一尺度（如今常用 RMSNorm）
  • FFN 前馈网络：每个词各自过一个两层网络
  • 位置：RoPE 按位置旋转 q、k，点积只取决于相对距离

留下的问题 注意力的计算量随长度 n 按 n² 增长（「推理效率」、「多模态、推理模型与长上下文」再处理）。更根本的问题是：架构有了，用什么任务、什么数据来训练，才能让它有通用的语言能力？
