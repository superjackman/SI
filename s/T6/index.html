多模态

看图、听声、画画都靠同一招。

看图、听声、画画都靠同一招：先把图片、声音变成和文字一样的 token / 向量，交给同一个大模型；生成侧再把向量还原。

为什么这样设计：复用已经很强的语言模型，只需要训练“转接头”，比每种模态从头做一个模型省得多。

▶ 打开互动版（能点图、做实验、做小测）

🧒 先用大白话说

大模型本来只认识文字。要让它看图、听声，就先把图片和声音翻译成它认识的“小积木”（和文字一样的一串编号或一串数字），再一起交给它。要它画画、说话时，再把积木拼回图片和声音。点图里的方块看每一步。

📑 这一站讲了什么

  • 多模态：一切都变成 token / 向量
    左边各种输入经编码器变成向量序列，排队进大模型；右边生成侧再把向量变回文字、图片、声音、视频、3D。点方块看详情。
  • 👁️ 看图：图片 → 切块 → ViT → 投影层 → 大模型
    看图时，先把图片像切豆腐块一样切成很多小方块，每块变成一串数字，再请大模型一起读。块切得小，细节清楚，但块数多、算得慢。点下面的块大小试试。
  • 👂 听声：波形 → 梅尔频谱 → 音频编码器
    声音录下来是一长串上上下下的数字，看着很乱。把它拆成“有哪些高音、低音，各有多响”（频谱），就像把一杯混合果汁分回各种水果，一下就清楚了。调两个音的高低和音量，听一听、看一看。
  • 🔗 对比学习对齐（CLIP 思路）：把图和文拉进同一个“意思空间”
    这是一个连连看：给模型很多“图片 + 它的说明”，让配对的图和话靠近，不配对的离远。练多了，“橘猫睡觉”这句话就会落在橘猫睡觉的照片旁边。按“训练一步”看表格怎么变。
  • ✍️ 生成·文字：自回归接龙
    写文字就是前面讲过的词语接龙：一次接一个。图片、声音变成积木之后，也能用同样的办法一块一块接出来。
  • 🖼️ 生成·图片：扩散 + 潜空间 + 文本条件
    画图像擦起雾的玻璃：从一团雪花点开始，按文字提示一点点擦清楚，每一步只擦一点，最后出现一张新图。拖动滑块看从清楚到全是雪花点、再变回来。
  • ⚠️ 容易混淆：扩散 vs 自回归
    写文章是一个字一个字往后写，这是自回归。扩散画图像擦起雾的玻璃：一开始全是雪花点，每一步把整面玻璃都擦清楚一点，最后出现一张图。
  • 🔊 生成·音频：声学 token + 声码器（或扩散）
    让模型说话、唱歌，就是把“听声音”倒过来：先写出“声音积木”或频谱，再交给声码器还原成能播放的声音。模仿别人的声音必须经过本人同意。
  • 🎞️ 生成·视频：时空潜空间 + 跨帧注意力，保持时序一致
    视频就是一张张连着放的图。如果每张单独画，同一只猫可能这张白、下张黄，画面会闪。所以要让所有画面一起商量着画。点按钮对比两种做法。
  • 🧊 生成·3D：多视图 + 重建，或分数蒸馏
    一个立体的东西，从哪个角度看都要说得通。常见做法是先画出同一个东西的几张不同角度的图，再像拼模型一样拼成立体的。拖动滑块转一转这个小雪人。
  • 🎙️ 实时语音 Agent：级联还是端到端
    和 AI 打电话有两种做法：一种是“听写—思考—朗读”三个人接力，每一段都能单独换和检查，但慢一些，语气也会丢；另一种是一个人直接听、直接说，快、能插话，但更难加检查。
  • 📄 读文档和截图：OCR、版面、表格
    让 AI 读文件和截图，不只是认字，还要看懂哪里是标题、哪里是表格、按钮在哪。小字、手写和模糊的图容易认错，所以金额和日期一定要自己再核对。
  • 🖌️ 按一句话改图，看懂一段视频
    除了画新图，AI 还能按你一句话改图（“把天空改成晚霞”），也能看懂一段视频。小窍门：一次只让它改一件事；问视频时说清是哪一段。
  • 🧪 扩散去噪游乐场：步数、提示词、引导强度 (动手实验)
