数学 · 推导与证明

反向传播 → p − y → √dₖ → 残差 → 策略梯度：模型关键公式的完整推导。

本站把前四站的工具用在真实模型上，逐步推导反向传播、输出层梯度、注意力缩放、残差梯度和策略梯度，并注明每条的假设和出处。

为什么这样设计：这些推导解释了模型为什么这样设计：不是拍脑袋，而是为了让梯度好好流动。

🧒 先用大白话说

前面几站学的工具（坡度、链式法则、机会大小、数表），在这里拿来解释真实模型里最重要的几条公式。就像学会了加减乘除，现在去算一笔真正的账。

每一条都一步一步证明，并写清楚它需要什么前提。看懂了这些，就知道模型为什么要这样设计：不是拍脑袋，而是为了让“该怎么调”的消息能顺利传到每个旋钮。

📑 这一站讲了什么

  • 把模型里最重要的几条公式，从头推一遍
    前四站准备好了工具，这里把它们用在真正的模型上：反向传播推导、输出层的softmax + 交叉熵的梯度 p−y、注意力的注意力的 √dₖ 缩放、残差连接的梯度…
  • 🔁 反向传播：两层网络的完整推导
    网络是一条一层接一层的流水线。最后算出错了多少，就要知道每个旋钮该往哪拧、拧多少。
  • ⚠️ 容易混淆：反向传播 vs 梯度下降
    反向传播像量坡度：从结果往回查，算出每个旋钮该往哪边拧、拧多少。梯度下降像真的去拧：按算出来的结果，把每个旋钮拧一点。先量，再拧。
  • 🧪 反向传播 vs 数值梯度：亲手验证推导 (动手实验)
  • 🎯 softmax + 交叉熵的梯度为什么是 p − y
    模型给每个词打分，softmax 把分数变成机会，交叉熵给“猜得多差”打分。这里有一个特别简洁的结果：每个分数该怎么调，就看“模型给的机会 − 正确答案的机会”。
  • 📏 注意力为什么除以 √dₖ
    注意力里，每个词拿自己的一串数（查询）去和别的词的一串数（键）“对应相乘再加起来”，得到一个配对分数。数串越长，加起来的项越多，分数就越容易变得特别大或特别小，就像抛 64…
  • 🛤️ 残差连接：梯度永远有一条直达通路
    残差连接：每一层不是把输入整个“换掉”，而是在原来的基础上加一点修改：输出 = 输入 + 修改量。就像改作文时在原稿上批注，而不是每次重写一遍。
  • 🎮 策略梯度：只知道“好不好”，也能求梯度
    训练模型做题时，有时只知道“答对给 1 分，答错给 0 分”，不知道“差多少”。这种分数本身没法求坡度。
