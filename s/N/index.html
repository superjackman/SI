神经网络入门

神经网络 = 很多“加权求和 + 激活”的小零件层层叠起来。

神经网络 = 很多“加权求和 + 激活”的小零件层层叠起来：前向算答案 → 损失量差距 → 反向传播算梯度 → 更新参数，循环很多遍就练成了。

为什么这样设计：与其手写规则，不如搭一个可调的大函数，让数据把每个旋钮拧到位；链式法则让几十亿个旋钮的调整方向一次算完。至于为什么这样训练出的大网络泛化得这么好，很多还是经验结论。

🧒 先用大白话说

神经网络是用很多个小零件搭起来的。每个零件只会一件事：把几个数各乘一个“重要程度”再加起来，然后过一道“开关”。成千上万个这样的零件一层层叠起来，就能做很复杂的事。

它的本事是练出来的：先猜一个答案，看错了多少，算出每个旋钮该往哪边拧，拧一点点，再来一遍。

📑 这一站讲了什么

  • 神经网络入门：从一个神经元到训练循环
    大模型的每一个零件，都是由最简单的“加权求和 + 激活”搭起来的；它的本事，全靠同一个循环练出来：前向 → 损失 → 反向传播 → 更新。点方块看详情，下面的实验可以亲手调。
  • 一句话记住每个零件
    一句话记住每个零件：神经元是最小的零件；很多神经元并排是一层；很多层叠起来是网络。损失是“错了多少”的一个分数；反向传播从错误往回查，算出每个旋钮的“责任”；学习率是每次拧多大。
  • ⚠️ 容易混淆：参数、权重、激活值、激活函数
    参数（权重）是模型学会以后记在本子上的数；激活值是做一道题时写在草稿纸上的数，做完就扔；激活函数是一条固定的规则，比如“负数一律变 0”。
  • 🧪 一个神经元：拖动权重看它怎么画线 (动手实验)
  • 🧪 激活函数对比：形状、斜率与梯度消失 (动手实验)
  • 🧪 反向传播一步一步算：计算图与链式法则 (动手实验)
  • 🧪 梯度下降下山：SGD / 动量 / Adam 与学习率 (动手实验)
  • 数据怎么喂：小批量与训练 / 验证 / 测试
    练习题要分成三份，像学校里的作业、小测和期末考：作业用来学；小测用来看学得怎么样、该什么时候停；期末考只在最后考一次，看真本事。每次只拿一小叠作业来改进，全部做完一遍叫一轮。
  • ⚠️ 容易混淆：训练集 vs 验证集 vs 测试集
    题目分三份：作业拿来学，小测用来看学得怎么样、该不该停，期末考最后只考一次。期末题不能提前看，不然分数就不算数了。
  • 初始化与归一化：让信号层层都“音量合适”
    信号要一层一层传下去，像传话游戏：每个人说话都大声一点，传几十个人以后就成了吼叫；每人都小声一点，最后就听不见了。所以开始时要把旋钮设成合适的大小，每层还要把“音量”调回正常。
  • 🧪 训练一个小网络：决策边界、过拟合与早停 (动手实验)
  • 正则化：别死记硬背
    只会死记硬背的学生，换一道新题就不会了。“正则化”就是各种防背题的办法：让旋钮别拧得太极端、练习时随机让一部分神经元休息、小测变差就停、多给些不同的练习题。
  • ⚠️ 容易混淆：过拟合 vs 欠拟合
    欠拟合像还没学会：作业都错一堆。过拟合像死记硬背：作业全对，换一道新题就不会。看作业和小测的成绩差多少，就知道是哪一种。
  • 卷积网络（CNN）：给图片用的神经网络
    看图片的网络用一块小放大镜在图上到处滑：同一块放大镜在哪儿都找同样的图案，比如一道边、一个角。一层层往上拼：边 → 纹理 → 零件 → 整个东西。这样要学的数字少得多…
  • 循环网络（RNN / LSTM）：为什么被 Transformer 取代
    老式的循环网络像一个人读书：一个词一个词地读，读过的都塞进一个小本子里，读到后面，前面的就记不清了，也没法几个人同时读。Transformer 让所有词一起读…
  • 🧪 词向量空间：近义词与类比 (动手实验)
  • 时间线：神经网络 80 年
    神经网络的想法已经有八十多年了。很多点子很早就有，2012 年以后突然变强，是因为三样东西终于凑齐：海量的数据、够快的显卡，以及让很深的网络也能练起来的小窍门。
  • 🎭 自编码器、VAE、GAN：生成模型的前传
    怎么让网络画出新东西？一种办法是先学会把图压缩成几个数再还原；然后随便挑几个数，就能还原出一张新图。另一种办法像造假币的和验钞的比赛：一个网络造图，另一个网络分辨真假…
