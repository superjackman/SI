大白话拆解 AI 的全部站点：从怎么用 AI、调用 API、本地跑模型，到 Agent、大模型、Transformer 内部和训练算力。每站都有图、实验和小测。

▶ 打开互动版（能点图、做实验、做小测）

  1. 应用全景 — 你说一句话，背后有六层接力。你说一句话，背后有六层接力：Agent 程序负责调度和动手，大模型负责“想”和“写”，训练体系离线把本事练出来，算力让一切跑起来。
  2. 怎么用 Agent — 同一个 Agent，八种用法；差别只在四件事。从“你怎么用它”的角度看 Agent：谁来发起、在哪里跑、能动什么、你要不要盯着。每种用法都能往下钻到原理那一侧。
  3. 跟它一起干 — 你在旁边看着，它一步步动手。对话助手、编辑器里的编程 Agent、命令行 Agent、操作电脑的 Agent：你开口、你看着、关键步骤你点头。
  4. 让它自己干 — 交出去，它独立跑完，你事后验收。后台 / 云端 Agent、例程与自动化、多 Agent 协作：没人在旁边看着，靠隔离、可检查的产出和人来按最后一步保证安全。
  5. 给它装本事 — 工具、MCP、Skills：不换模型，多会几样。工具给它新动作，MCP 让它接上别人做好的工具，Skills 给它按需加载的做法说明。它们的说明都要占上下文。
  6. 用得好 — 说清楚、管好上下文、自己验证。同一个 Agent，交代得清不清楚、上下文干不干净，结果差很多：四件事说全、给相关的、先计划、再验证、守住安全习惯。
  7. 具体产品 — 按用法找产品，附官方链接。把真实的 Agent 产品按“用法”归类，每个附官网、出品方和一句话介绍，可按用法、国内运营、开源筛选。最后核对 2026-10-23，以官网为准。
  8. API 调模型 — 密钥、接口格式、怎么算钱。API 就是让你的程序代替你去问模型：带上密钥，发到平台地址，按输入、输出的词元数付钱。
  9. 本地跑模型 — 装得下吗、用什么工具、下载哪个文件。本地跑模型：把开放权重的模型文件下载到自己电脑上运行，资料不出门、不按词元付费，但要看内存装不装得下。
  10. 让 AI 替我干活 — 按事情选 Agent，陪你干还是自己干，再检查结果。先说清要干的事，再选陪你干还是自己干，最后自己检查结果。
  11. 给 AI 装技能 — 工具、MCP、技能包、提示模板：按事情选，装之前看权限。缺“手”装 MCP 服务器，缺“方法”装技能包；从官方来源装，只给需要的权限。
  12. 自己搭 Agent — 零代码平台或写代码：搭的都是“模型想 → 跑工具 → 再想”的循环。不会代码用平台拖，会代码用 SDK 写循环；步骤固定就用工作流。
  13. Agent — Agent = 大模型 + 一个循环程序。Agent = 大模型 + 一个循环程序：模型写出“要调用哪个工具”，程序去执行，再把结果喂回模型，直到事情办完。
  14. 大模型 — 大模型就是一台“猜下一个词”的机器。大模型就是一台“猜下一个词”的机器：文字切成 token → 变成向量 → 几十层加工 → 给每个候选词打分 → 抽一个接上去，反复进行。
  15. 神经网络入门 — 神经网络 = 很多“加权求和 + 激活”的小零件层层叠起来。神经网络 = 很多“加权求和 + 激活”的小零件层层叠起来：前向算答案 → 损失量差距 → 反向传播算梯度 → 更新参数，循环很多遍就练成了。
  16. Transformer 块 — 每个 Transformer 块做两件事。每个 Transformer 块做两件事：先让词和词互相“看一看”（注意力），再让每个词自己“消化”（前馈网络）；残差和归一化保证几十层叠起来还能训练。
  17. 注意力 — 注意力 = 每个词拿着提问卡（Q）去和所有词的标签卡（K）比相似度。注意力 = 每个词拿着提问卡（Q）去和所有词的标签卡（K）比相似度，再按比例把它们的内容卡（V）混合起来。
  18. 前馈与输出 — 前馈网络把每个词的向量放大、过滤、再缩回。前馈网络把每个词的向量放大、过滤、再缩回，像查一本“知识字典”；最后的输出打分层给词表里每个词打分，softmax 变成概率。
  19. MoE 与高效架构 — 同样的本事怎么更省。同样的本事怎么更省：MoE 让每个词只用部分专家，KV 缓存避免重复计算，量化让数字变短，LoRA 只训练小补丁，投机解码让小模型先猜。
  20. 多模态 — 看图、听声、画画都靠同一招。看图、听声、画画都靠同一招：先把图片、声音变成和文字一样的 token / 向量，交给同一个大模型；生成侧再把向量还原。
  21. 训练与强化学习 — 本事不是写出来的，是练出来的。本事不是写出来的，是练出来的：先用海量文本自学“猜下一个词”，再看示范学格式，最后用奖励和偏好打磨。
  22. 速查与全景图 — 所有零件的关系图和术语表。所有零件的关系图和术语表，加上你的学习进度、测验成绩和全部实验入口。
  23. 数学 · 微积分 — 极限 → 导数 → 链式法则 → 梯度：训练时“往哪边调参数”的数学。本站讲神经网络训练用到的微积分，每个结论给出逐步证明；数学公式在本机渲染，不依赖外部服务。
  24. 数学 · 线性代数 — 向量 → 矩阵 → 行列式 → 雅可比：模型里“一层”到底算了什么。本站讲神经网络用到的线性代数，并逐步证明点积的几何意义、转置法则、面积公式和梯度的转置规则。
  25. 数学 · 概率与信息 — 分布 → softmax → 交叉熵 → KL：模型怎么表达“不确定”，又怎么被打分。本站讲语言模型用到的概率与信息论，并逐步证明方差公式、贝叶斯公式、softmax 平移不变、交叉熵分解和 KL ≥ 0。
  26. 数学 · 优化 — 最陡下降 → 学习率 → 小批量 → Adam：训练循环每一步的数学。本站证明负梯度是最陡下降方向、学习率的收敛条件、小批量梯度无偏且方差按 1/B 下降，以及 Adam 偏差修正的来历。
  27. 数学 · 推导与证明 — 反向传播 → p − y → √dₖ → 残差 → 策略梯度：模型关键公式的完整推导。本站把前四站的工具用在真实模型上，逐步推导反向传播、输出层梯度、注意力缩放、残差梯度和策略梯度，并注明每条的假设和出处。
