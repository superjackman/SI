从“用样本找函数”到 Agent 与应用：23 站自底向上推导大模型。

▶ 打开互动版（能点图、做实验、做小测）

  1. 用样本找函数 — 有些任务写不出一张事先列完的表：“这张图里是不是猫”“这句话接下来该说什么”。一条一条写，永远写不完。有些事没法事先列成一张死表：「这是猫吗」「下一句说什么」。换个办法：先给一排能拧的旋钮，用看见的例子把它们拧对…
  2. 概率基础 — 语言模型要预测「下一个字」，就必须先会说「可能性」。每猜下一个字，其实是在说「接下来每个字有多大可能」。这份可能从 0 到 1，全部加起来必须是 1。
  3. 损失函数 — 需要一个数字来衡量“模型错了多少”，越小越好。每猜一次，都要先知道这次错了多少。正负不能直接相加，不然会互相抵消。这个数就是罚分，要把它越拧越小。
  4. 梯度下降 — 求 L(θ) 的最小值，而且参数很多。旋钮有几十亿颗，不可能一颗颗去试。蒙着眼走下一只碗：每一步只摸脚下哪边最陡，就朝反方向迈一小步。顺着坡往下走，这件事叫梯度下降。
  5. 多层 + 非线性 — 线性模型（包括单个感知机）只能用一条直线（高维是一个超平面）把两类分开。四个点坐在对角上，一条直线怎么画都有一个站错队。中间要弯一下，只把直线叠很多层还是分不开。
  6. 反向传播 — 高效地求出所有参数的梯度。前面那颗旋钮怎么拧？不能靠猜。先看最后的罚分是谁弄大的，再把这个原因乘着从后往前传。
  7. 训练工程 — 训练要快、要稳、还要能泛化。数据有上百万条时，每一步看完全部太慢。还得留一份没拿来拧旋钮的例子，变差了就停，免得把练习册背下来。
  8. 词向量 — 把离散的词变成向量，最好让向量带有语义。电脑不认「猫」这个字，只认数。要让数带着意思，就给每个字一排能比方向的数，而不是一个互不相干的编号。
  9. RNN + 注意力 — 对变长序列建模，让同一个词的表示随上下文变化。句子有长有短。一个词一个词往后传，开头会越来越淡。所以每一步都要能回头看整句，不能只靠那张纸条。
  10. 注意力：谁和谁有关 — 让每个词能直接看到句子里任何一个词，而且所有位置可以同时算（Vaswani 等，2017，《Attention Is All You Need》）。“小猫坐在垫子上，因为它很累。”“它”是谁？人一眼就知道是小猫。…
  11. 组装成 Transformer — 把注意力做成能叠很多层、又稳又能分辨词序的完整模型。回头看名牌，只是一层里的一件事。大模型像一栋楼，同一种楼层叠很多层。每一层先对名牌，再把原来的说法加回去，然后各自消化。
  12. 预训练 — 人工标注数据太少，需要一个能用上海量无标注文本的训练任务。房子有了，用什么来练？让它猜下一个字。这一句里的每一个字都能当答案，不用另外找人来标。
  13. 评估 — 模型训完了，怎么客观知道它有多强、哪里不行？练完以后，不能靠感觉说「它变强了」。犹豫变少也不等于答对了，要用同一把尺子量。
  14. 后训练：SFT、对齐与推理 — 让模型听懂指令、回答有用、足够安全，并学会“想清楚再回答”。只会接着往下写，还不等于听得懂吩咐。还要先照着示范改格式，再按人指出的哪一份更好去靠。
  15. 低成本适配 — 全量微调要为每个参数存梯度和优化器状态：按混合精度 + Adam 粗估每参数约 16 字节 粗略估算，7B 模型约 112GB 显存，还不算激活值；每个任务还要另存一整份模型。把整块都解开再拧，太贵。大块冻住…
  16. 推理效率 — 自回归生成只能一个词元一个词元地输出，不能像训练那样并行。字只能一个一个往外写。已经算过的记在本子上，下一步只算新的那个字，不用把 1 一直加到 100。
  17. RAG — 知识过期、缺私有知识、幻觉，以及回答没法溯源。它会过期，也会编。别逼它把资料背下来。先按方向找出相关的一段，再看着这段来答，并写上是哪一段。
  18. 工具与 Agent — 让模型与外部世界交互，完成多步任务。只会说还不够，还得能办事：查天气、改日历。它只写下要办的那一件，旁边的人去办，会改掉东西的那一步要等人点头。
  19. 安全 — Agent 会调工具之后，怎样防止被骗、越权、泄密？它一旦能办事，要防的就不只是说错话。会改数据、会花钱的动作，做错了是真的发生。
  20. 多模态 — 理解和生成图像、语音等，不只是文字。世界不只有字。截图、照片、声音也要能读，办法是先切成小块，再当成词。
  21. 推理模型与长上下文 — 回答时多花算力，以及一次塞进更长的文字。难题可以让它多写几份再答，留下出现得最多的那份。很长的一篇，窗口变长也不等于中间也被用到。
  22. 应用实战 — 把前面各站拼起来：现在这些能力都用在哪？学完这些，最想知道的是现在能拿来做什么。能交出去的用法，是把读、改、测试排好顺序，不是再加一排新旋钮。
  23. 回顾 — 把整条链串成一句话，再决定从哪里动手。整条链可以收成一句话：用看见的例子把旋钮拧对，罚分往下走。任务换成了看图和办事，这一套没有换。
