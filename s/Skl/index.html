给 AI 装技能

工具、MCP、技能包：按事情选，先看权限。

缺“手”装 MCP 服务器，缺“方法”装技能包；从官方来源装，只给需要的权限。

为什么这样设计：装对了，Agent 能连上你的文件和网上的服务；装错了，等于把钥匙交给陌生人。

▶ 打开互动版（能点图、做实验、做小测）

🧒 先用大白话说

📏 这里讲：工具、MCP 服务器、技能包、提示模板有什么不同，按事情怎么选，真实的目录在哪，怎么装、装之前看什么。这里不讲：怎么自己写 MCP 服务器（见“自己搭 Agent”）、海外服务怎么开通。

给 AI 装技能像给手机装 App：先想清楚要它多会什么，再去正规的应用商店装，装的时候看它要哪些权限。

📑 这一站讲了什么

  • 🧪 3D 给机器人插工具
  • 🧰 给 AI 装技能：缺“手”还是缺“方法”
    Agent 本来只会“说”。想让它多会一件事，有四种加法：
  • 🧭 按要做的事选：用哪种加法
    要它碰到东西（文件、网页、地图）就装 MCP；要它照着做法做就装技能包；只是每次说同样的话，存个提示模板就够。
  • 📚 真实的 MCP 服务器和技能包（按用途）
    这里每一项都链到官方页面。像在官方应用商店挑 App：名字很像的陌生包不要装。
  • 🔩 装一个 MCP 服务器：其实是改一段配置
    装 MCP 服务器其实就是在设置里填一段配置：起个名字、写怎么启动、写它能碰哪个文件夹。
  • 🛡️ 装之前：权限、来源、密钥
    装一个服务器等于给 AI 一把钥匙。先看钥匙能开哪些门：只给需要的文件夹，密钥不贴进对话。
  • ⚠️ 容易混淆：MCP 服务器 vs 技能包
    MCP 服务器是手，技能包是说明书。有手没说明书会乱做，有说明书没手做不了，常常两样一起用。
  • ⚠️ 容易混淆：技能包 vs 提示模板
    提示模板像你随身带的便签，每次自己贴上去；技能包像放在 AI 书架上的手册，它需要时自己去翻。
