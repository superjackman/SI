Using agents

One agent, eight ways to use it; they differ in four things.

Agents seen from “how you use them”: who starts it, where it runs, what it can touch, and whether you watch. Each way links down to how it works.

Why it’s designed this way: Knowing how it can be used first gives the principles something to hang on.

▶ Open the interactive version (tap the diagram, try labs, take the quiz)

🧒 In plain words

An Agent is like a helper that can actually do things. There are many ways to use it, but inside it is always the same thing. The ways differ in only four things: who tells it to start, where it works, what it can touch, and whether you watch.
