Change one mistake and see the tests

A fare rule written on the page, and two tests that run here. You pick a change, and the page recomputes the same expected numbers. This is not a live model call, it asks for no key, and it does not need Python.

The sample

Rule: 3 yuan for the first kilometre, then 2 yuan for each kilometre after that. The current code charges 2 yuan for every kilometre. Tests: 1 km should be 3, and 3 km should be 7.

Steps

  1. Look at the two tests as they stand. Both are red.
  2. Pick “Change it to match the rule”. The page recomputes.
  3. Both turning green is the finished result.

When it works

After the change that matches the rule, 1 km gives 3 and 3 km gives 7. Both pass.

One way it fails

Pick “3 yuan for every kilometre”. 1 km happens to be 3, and 3 km gives 9, not 7. The second test stays wrong.

Programmers can open fare. All three formulas are on the page. The tests compare those two inputs with the expected numbers.

This is a fixed sample, not a live model call, and it asks for no key.
