An assistant that asks you before it acts

One fixed job: send a draft. The assistant reads the action out and waits for you. This is not a live model call, and it asks for no key.

The sample

Task: send the draft “Weekly notes” to the project group. The action it is about to take: send a mail, to the project group, titled Weekly notes.

Steps

  1. Read the task and the action it is about to take.
  2. Tap “Ask me first”. It stops and asks whether to send.
  3. “Sent” appears only after you agree. Cancel leaves it unsent.

When it works

The question “Send it to the project group?” appears first, and “Sent” is not there yet. “Sent (sample)” appears only after you agree.

One way it fails

Tap “Send without asking”. The page marks that this path labeled the sample sent without asking you. That path is the failure.

Programmers can open decide. It only looks at the button you tapped. It calls no API.

This is a fixed sample, not a live model call, and it asks for no key.
