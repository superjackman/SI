A tiny knowledge base that cites its notes

Three fixed notes. You pick a question, and the page takes a sentence only from the note that matches. This is not a live model call, and it asks for no key.

The sample

Note A: the shuttle leaves the east gate at 7:40. Note B: the meeting room is on floor 3, and the key is at the front desk. Note C: the printer is closed on Friday.

Steps

  1. Read the three notes.
  2. Pick a question. A question that matches names the note.
  3. Read the answer. The note’s own sentence follows it.

When it works

Ask “What time does the shuttle leave the east gate?”. The answer is 7:40, from the sentence on note A.

One way it fails

Ask “What is on the cafeteria menu today?”. None of the three notes says it, so the page says so and does not invent a sentence.

Programmers can open the match function. It picks a note by the question id. There is no vector and no request.

This is a fixed sample, not a live model call, and it asks for no key.
