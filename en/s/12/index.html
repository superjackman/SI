Inference speed

KV cache, GQA/MLA, FlashAttention, speculative decoding, MoE

▶ Open the interactive version (diagrams, labs, quizzes)

The problem Autoregressive generation emits one token at a time; it can’t parallelise like training.

Why care

Generation is serial. KV cache, shared KV, FlashAttention, speculative decoding, MoE cut work and memory.

Everyday analogy

  • Remember past K, V.
  • Share KV across heads; MoE wakes a few experts per token.

Core idea

  • KV cache: earlier tokens’ K and V never change, so store them and compute only the new token’s q, k, v. But the cache grows with length, and speed is often limited by memory bandwidth, not compute.
  • MQA / GQA: query heads share K and V (MQA: one set for all; GQA: one per group). MLA (DeepSeek-V2, 2024): cache a compressed low-dimensional latent instead — low rank again.
  • FlashAttention (Dao et al., 2022): exactly the same result as standard attention; it saves memory traffic by computing in tiles in on-chip memory with an “online softmax”, never writing the n × n matrix out.
  • Speculative decoding: a small model guesses k tokens, the big model checks them in one parallel pass and keeps the accepted prefix; with the right acceptance rule the output distribution matches the big model’s.
  • MoE: replace the FFN with many experts and route each token to the top-k; huge total parameters, few active per token — but memory stays large and the load must be balanced.

What the picture shows

  • New token → its q,k,v → attend with cached K,V.

The numbers

  • Under , ~0.5MB/token; 100 tokens without cache need K,V computes.
  • KV cache (same setup as card KC14): ; 32 KV heads × head size 128 = 4096 example setup.
  • per token = 2 × 32 × 32 × 128 × 2 = 524,288 bytes ≈ 0.5 MB; the whole context — for one request.
  • With GQA’s 8 KV heads the cache drops to 1/4, about 0.5 GB.
  • Generating 100 tokens: without a cache K, V computations; with a cache only 100.

Formula

  • cache bytes ≈ 2 × layers × KV heads × dim × bytes
  • Cache per token = 2 × layers × KV heads × head size × bytes per number
