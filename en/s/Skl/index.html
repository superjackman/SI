Add skills to AI

Tools, MCP, skill packs: pick by job, check access.

Missing a hand: an MCP server; missing a method: a skill pack; install from official sources with only the access needed.

Why it’s designed this way: The right add-on connects the agent to your files and services; the wrong one hands your keys to a stranger.

▶ Open the interactive version (tap the diagram, try labs, take the quiz)

🧒 In plain words

📏 Covered here: how tools, MCP servers, skill packs and prompt templates differ, which to pick for a job, where the real catalogues are, how to install, and what to check first. Not covered: writing your own MCP server (see “Build an agent”), or signing up for overseas services.

Adding skills to an AI is like installing apps on a phone: decide what you need, install from a proper store, and look at the permissions it asks for.

📑 What this stop covers

  • 🧪 3D plug tools into the robot
  • 🧰 Add skills to an AI: a hand or a method?
    An agent can only talk at first. To teach it one more thing there are four add-ons:
  • 🧭 Choose by the job: which add-on
    If it must touch things (files, web pages, maps), install MCP; if it must follow a method, add a skill pack; if it is just the same words each time, save a prompt template.
  • 📚 Real MCP servers and skill packs (by use)
    Every entry links to its official page. Like shopping in the official app store: skip unknown look-alike packages.
  • 🔩 Installing an MCP server: really just a config snippet
    Installing an MCP server is really filling a snippet into settings: a name, how to start it, and which folder it may touch.
  • 🛡️ Before installing: access, source, secrets
    Installing a server is like giving the AI a key. See which doors it opens first: only the folders it needs, and no keys pasted into chats.
  • ⚠️ Easy to mix up: MCP server vs skill pack
    An MCP server is a hand; a skill pack is a manual. A hand without a manual flails; a manual without a hand cannot act; they often go together.
  • ⚠️ Easy to mix up: skill pack vs prompt template
    A prompt template is like a sticky note you carry and paste each time; a skill pack is like a manual on the AI’s shelf that it opens when needed.
