Why care

One sentence holds the chain: from fitting a function to agents and apps, each step answering the last gap.

Everyday analogy

  • The pyramid shows structure; this path shows how it was forced into being.
  • Progress is mastery (quizzes), not merely “visited”.

Core idea

  • Fit a function → probability → loss → gradient descent → non-linearity → backprop → training engineering → embeddings & tokenisation → RNN/attention → Transformer → pre-training & sampling → evaluation → post-training → LoRA/quantisation → inference efficiency → RAG → agents → safety → multimodal → test-time compute → applications.
  • How to learn it: implement each piece from scratch in Python + NumPy first, then look at a framework. Check one idea at a time, like writing a unit test. Every step ends with a “try it” line.
