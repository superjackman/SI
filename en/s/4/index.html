Backpropagation

The chain rule; ReLU, residuals, normalisation

▶ Open the interactive version (diagrams, labs, quizzes)

Get the gradients of all parameters, efficiently.

How do early knobs get their gradients? The chain rule, run backwards efficiently — backprop.

  • Gears in a row: how much the last turned tells how to nudge earlier ones.
  • Backprop does this automatically.
  • Long chains vanish — ReLU, residuals, normalisation keep a path.
  • A network is nested functions L = f3(f2(f1(x))); the chain rule multiplies the local derivatives.
  • Backpropagation: run forward to get each layer’s values, then pass “upstream gradient × local derivative” back layer by layer. Reusing the intermediate results makes one backward pass cost about one forward pass (Rumelhart, Hinton and Williams made it widely known in 1986); it is what “autograd” in every framework does.
  • New problem — vanishing / exploding gradients: sigmoid’s slope is at most 0.25, and 0.25^10 ≈ 0.00000095 over 10 layers. Fixes: ReLU (slope 1 when positive), residuals (y = x + F(x) always has a path with slope 1; ResNet, He et al., 2015), normalisation (LayerNorm and others), and initialisation scaled to layer width (never all zeros).
  • Forward values → backward gradients → every ∂L/∂w.
  • dL/dx = 0.5 × 3 × 2 = 3; see the ReLU toy numbers on this page.
  • Chain rule : dL/dx = 0.5 × 3 × 2 = 3; now a small network with a ReLU.
  • y = w2 × ReLU(w1 × x), L = (y − t)², with x = 1, w1 = 2, w2 = 3, t = 5.
  • Forward: h = 2, y = 6, L = 1. Backward: dL/dy = 2(6 − 5) = 2.
  • dL/dw2 = 2 × h = 4; dL/dh = 2 × w2 = 6, and h > 0 so dh/dw1 = x = 1, giving dL/dw1 = 6.
  • dL/dx = dL/df × df/dx
  • residual y = x + F(x) → a path with derivative 1
  • dL/dx = dL/df3 × df3/df2 × df2/df1 × df1/dx
  • Residual: y = x + F(x), so dy/dx = 1 + dF/dx

  • local
  • further back

Left open Gradients work, but with millions of examples a full pass per step is too slow; different parameters want different step sizes; and the model may just memorise the training set.
