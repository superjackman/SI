On 5 Nov 2026 OpenAI announced a model for authorized security…

2026-11-05 · OpenAI · 2026-11-02

On 5 Nov 2026 OpenAI announced a model for authorized security research, trained to stay inside the scope a researcher sets. Before using that kind of tool, read the safety stop: untrusted text is not a new instruction, and high-risk actions wait for a person.

The source says the model is for authorized security research, and that training includes staying inside a scope the researcher sets.

Stop S, “high-risk actions wait for a person”: paying, deleting and sending stop for a nod. A read-only lookup can run alone.

The same stop treats a slipped-in note as data, not as a new instruction. “Stay inside the scope” in the source is that kind of boundary.

Stop 14 continues: the model only writes the call, and a program runs it, so the program is where a high-risk action can be stopped.
