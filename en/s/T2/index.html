Agent

Agent = LLM + a loop program.

Agent = LLM + a loop program: the model writes “which tool to call”, the program runs it and feeds the result back to the model, until the job is done.

Why it’s designed this way: The model itself can only write text — it can’t go online or change a calendar — so a program has to act for it and keep watch for you.

▶ Open the interactive version (tap the diagram, try labs, take the quiz)

🧒 In plain words

A large model is like a clever person who can talk but has no hands: it can think and write, but it cannot go online or press a button by itself. An Agent is the helper program at its side: when the model says “go and check the weather”, the helper really does it and reads the result back; then the model decides the next step. Round and round, until the job is done.
