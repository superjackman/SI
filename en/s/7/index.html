RNN + attention

A recurrent state; attention eases the bottleneck

▶ Open the interactive version (diagrams, labs, quizzes)

Model sequences of any length, so a word’s representation changes with its context.

Sequences vary in length. RNNs read step by step but forget and cannot parallelise; attention looks at all positions.

  • RNN passes a small note along a line.
  • Attention scans every name-tag each time and listens by relevance.
  • RNN: keep a memory vector h and update it word by word, reusing the same parameters at every step.
  • Problems: back-propagating through time multiplies gradients many times, so long-range dependencies are hard; h_t must wait for h_(t−1), so there is no parallelism. LSTM/GRU gates and a mostly additive cell state help (much like residuals) but don’t cure it.
  • The seq2seq bottleneck: in translation the encoder squeezes the whole sentence into its last vector; long sentences lose information.
  • Attention (Bahdanau, Cho and Bengio — proposed 2014, published at ICLR 2015): for each output word, look back at every encoder position, score them, softmax into weights and take the weighted sum — a context vector made for this step.
  • RNN updates h; attention scores all h and mixes them.
  • Scores [2, 1, 0] → shares [0.665, 0.245, 0.090] .
  • Scores for 3 source words [2, 1, 0]: e² ≈ 7.389, e¹ ≈ 2.718, e⁰ = 1, total 11.107.
  • Weights ≈ [0.665, 0.245, 0.090]: the model mostly “looks at” the first word (“Attention: who relates to whom” and card use the same numbers).
  • RNN : inputs x = 1, 0, 0, 0 → h = 0.76 → 0.36 → 0.18 → 0.09: the first token’s influence roughly halves each step.
  • Softmax : scores 2.0 / 1.0 / 0.1 / −0.5 → 62.5% / 23.0% / 9.4% / 5.1%.
  • aᵢ = softmax(eᵢ); c = Σ aᵢ hᵢ
  • h_t = tanh(W × h_(t−1) + U × x_t + b)
  • Weights a_i = e^(e_i) / Σ e^(e_j); context c = Σ a_i × h_i
  • Weights are computed, not stored parameters

Left open Attention works, but it still rides on an RNN that runs step by step. Attention already links any two positions directly — can we drop the recurrence and keep only attention?
