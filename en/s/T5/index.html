MoE & efficiency

How to get the same ability more cheaply.

How to get the same ability more cheaply: MoE uses only some experts per word, the KV cache avoids recomputation, quantization shortens the numbers, LoRA trains only a small patch, and speculative decoding lets a small model guess first.

Why it’s designed this way: Bigger models work better but cost more; all these tricks look for a better balance between “quality” and “cost”.

▶ Open the interactive version (tap the diagram, try labs, take the quiz)

🧒 In plain words

This stop is about ways to save: making large models cheaper and faster to run, and able to read longer texts. Like running a restaurant: hire many specialist cooks but call only one or two per dish, prepare ingredients in advance, use smaller plates, and let an apprentice try first while the head chef checks.
