Tools + agents

Function calling, the agent loop, MCP

▶ Open the interactive version (diagrams, labs, quizzes)

Let the model act in the outside world and finish multi-step tasks.

Talking is not enough — act: call tools. The model writes the call; a program runs it.

  • Show tool schemas first.
  • It emits call JSON; the program runs and returns results.
  • Loop observe → think → act until done.
  • Tool calling: describe the tools (name, JSON Schema for arguments); when needed the model outputs a structured request such as {"name": "get_weather", "arguments": {"city": "Shanghai"}}; your program runs it and puts the result back in the context. The model executes nothing — it only decides what to call.
  • The agent loop: observe → think → act → see the result → … until done (ReAct, Yao et al., 2022), plus planning (sub-tasks), memory (the context is short-term; outside stores are long-term) and reflection (run tests, compare with the goal, retry).
  • MCP: an open protocol Anthropic released in November 2024 — JSON-RPC 2.0, client-server — exposing tools, resources and prompt templates to model apps in one way, turning M apps × N tools of glue code into M + N.
  • Hard parts: compounding errors, permissions and safety (prompt injection, overreach — least privilege, sandboxes, a human confirms risky steps, keep instructions apart from data), evaluation and cost. Several cooperating agents sometimes help, but not always more than one.
  • Observe → think → act → observe … → stop/ask.
  • Rainy outdoor meeting: weather → calendar → confirm → update.
  • “If it rains in Shanghai tomorrow, move my outdoor meeting online.”
  • Weather tool (80% rain) → calendar tool finds the meeting → draft the change → ask the user → calendar update tool: 4 tool calls, one of them a human confirmation.
  • 0.95^20 ≈ 0.36
  • At 95% success per step, all 20 steps succeed with probability 0.95^20 ≈ 0.36
  • The model is not the executor; see the Safety station

Left open It can call tools. Next: safety — injection, jailbreaks, permissions, confirmation.
