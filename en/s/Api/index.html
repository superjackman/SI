Model APIs

Keys, the request format, and what it costs.

An API lets your program ask the model for you: attach a key, send to the platform’s address, pay by input and output tokens.

Why it’s designed this way: To put a model into your own site, script or tool, you go through an API.

▶ Open the interactive version (tap the diagram, try labs, take the quiz)

🧒 In plain words

📏 Covered here: calling a model from your program through a platform’s API, keeping the key safe, and what it costs. Not covered: how to reach or sign up for overseas platforms.

An API is like a takeaway window: your program passes in the order (the question), the kitchen (the model on the platform) passes out the dish (the answer), and you pay by portion (tokens). The key is your membership card: lose it and someone else spends your money.
