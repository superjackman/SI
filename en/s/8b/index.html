Building the Transformer

Heads, FFN, residuals, normalisation, position

▶ Open the interactive version (diagrams, labs, quizzes)

Turn attention into a full model that stacks many layers, trains stably and can tell word order.

Attention is only one part. A real large model is like a tower: the same kind of floor (a decoder block) stacked dozens of times. Each floor does two things: first talk (attention), then think it over alone (the feed-forward network).

  • Like a team of detectives in a meeting: each detective follows one lead (multi-head: one checks who “it” is, one looks at neighbours, one looks for causes); after the meeting everyone goes back to their desk to think (the feed-forward network, FFN).
  • Each time they only write notes on the draft and never rewrite it (the residual); before each meeting everyone’s volume is set to the same level (normalisation); and everyone carries a seat number, or nobody could tell who came first (position encoding).
  • Multi-head: split the dimensions into h parts, attend in each, concatenate; each head can learn one kind of relation (e.g. reference, neighbours, cause).
  • Position: attention ignores order; most models now use RoPE (Su Jianlin et al., 2021, RoFormer), rotating q and k by position so their dot product depends only on the distance; over time: sinusoidal (original paper) → learned (GPT-1/2) → RoPE (mainstream today).
  • FFN: a two-layer network applied to each position, inner width about 4× typical, varies by model the model width; activation over time: ReLU (original) → GELU (GPT) → SwiGLU (common today).
  • Residual + normalisation let it stack many layers; normalisation over time: original Post-LN (this site’s diagram) → Pre-LN from GPT-2 on → RMSNorm in newer models.
  • One decoder block: the input is normalised, multi-head attention lets words talk, and the result is added back to the input; then normalise again, the FFN thinks, and the result is added back. The same block is stacked N times, then the output head. Position rotates q and k inside attention (RoPE).
  • The original paper stacked N = 6 decoder layers; today’s large models often stack dozens.
  • The original paper: model width d = 512 and h = 8 heads, so each head has 512 ÷ 8 = 64 dimensions.
  • Parameter count, roughly: each decoder block has about 12 × d² parameters (attention 4 × d² + feed-forward 8 × d²) rough, embeddings not counted .
  • MultiHead(x) = Concat(head1, …, headh) × W_O
  • x = x + Attention(Norm(x))
  • x = x + FFN(Norm(x))
  • MultiHead(x) = Concat(head1, …, headh) × W_O
  • x = x + Attention(Norm(x)), x = x + FFN(Norm(x))
  • RMSNorm(x) = x / √(mean(x²) + ε) × g
  • Multi-head: cut the width into h parts, run attention in each, and join them back
  • + the residual: add the result back to the input, so the draft is kept and the gradient has a straight path
  • Norm normalisation: pull each word’s numbers back to one scale (RMSNorm is common today)
  • FFN the feed-forward network: each word goes through its own two-layer network
  • Position: RoPE rotates q and k by position, so their dot product depends only on the distance

Left open Attention costs grow with n² for length n (“Inference speed”, “Multimodal, Reasoning models + long context” return to this). The deeper question: with the architecture in hand, what task and what data give it general language ability?
