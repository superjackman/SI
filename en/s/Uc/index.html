Extend it

Tools, MCP, skills: new abilities without a new model.

Tools give it new actions, MCP plugs in tools others built, and skills give it know-how loaded on demand. All their descriptions take context.

Why it’s designed this way: Changing the model is slow and costly; manuals and hands from outside work the same day.

▶ Open the interactive version (tap the diagram, try labs, take the quiz)

🧒 In plain words

What a model knows is fixed once it is trained. The easiest way to make it do more is to hand it instruction sheets and give it “hands”, like installing apps on a phone. There are three ways: add tools one by one, plug in a whole set someone else built (MCP), or give it a pack of “how-to notes” (Skills). The cost: every instruction sheet takes up room on its “desk” (the context).
