Learn a function from examples

A model with parameters + supervised learning

▶ Open the interactive version (diagrams, labs, quizzes)

The problem Some tasks have no writable rules: “is there a cat in this picture?”, “what comes next in this sentence?”. You could never finish the if-else.

Why care

Some tasks beat if-else: “is this a cat?”, “what comes next?”. Give a tunable function, then twist its knobs with examples.

Everyday analogy

  • Like a radio: knobs are parameters; reception is tuned by many samples.
  • The goal is songs you have not heard still come through — generalisation.

Core idea

  • Instead of rules, take a family of functions with knobs (the parameters θ) and turn the knobs using many “input → right answer” examples. This is a parametric model + supervised learning.
  • The goal is to generalise: be right on inputs it has never seen.
  • Large models use the same frame; θ is just billions of numbers.

What the picture shows

  • x → function with θ → prediction; examples tune θ.

The numbers

  • Samples (1,3), (2,5), (3,7) → y = 2x + 1 by eye.
  • Examples (1, 3), (2, 5), (3, 7): you can see y = 2x + 1, so w = 2, b = 1.
  • With 100 million examples and 1000-dimensional x you can’t see it; the machine has to search.

Formula

  • ŷ = f(x; θ)
  • θ is sometimes two numbers, sometimes billions
  • y_pred = f(x; θ), θ = all the parameters
  • The simplest, a linear model: y_pred = w × x + b
  • x input
  • θ parameters
  • ŷ prediction
