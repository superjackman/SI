Pre-training

Next-token prediction + scale

▶ Open the interactive version (diagrams, labs, quizzes)

Human-labelled data is scarce; we need a task that can use oceans of unlabelled text.

Scores 4.1 / 1.3 / 1.0. At temperature T = 1, what are the three probabilities?

T = 1 → 90% / 5.5% / 4.1%. T = 0.5 → 99.4% / 0.4% / 0.2%. T = 2 → 69% / 17% / 15%.

With the architecture ready, train by next-token prediction, and learn sampling to turn probabilities into text.

  • Fill-in-the-blank at scale.
  • BPE sets token size (see “Word vectors”).
  • Decoding: temperature / top-k / top-p.
  • Next-token prediction: given the text so far, predict the next token (in this site’s Chinese demo 1 token ≈ 1 character); the text is its own label. Predicting well forces it to pick up grammar, facts and some reasoning (a widely held intuition, not a proof).
  • Tokenising (BPE): start from characters or bytes and keep merging the most frequent adjacent pair into a new token until the vocabulary reaches tens of thousands to a couple of hundred thousand.
  • Scaling laws: Kaplan et al. (2020) and Hoffmann et al. (2022, Chinchilla) observed loss falling roughly as a power law in parameters N, data D and compute C empirical; Chinchilla used 70 billion (70B) parameters and 1.4 trillion (1.4T) tokens — about 20 tokens per parameter rule of thumb. Today smaller models are often trained far past that ratio to make inference cheaper.
  • Training compute C ≈ 6 × N × D floating-point operations rough estimate; data quality (dedup, filtering, mixing) matters as much as quantity.
  • Emergent abilities: some studies report abilities “appearing suddenly” past a scale; others (Schaeffer et al., 2023) argue this is largely an artefact of discontinuous metrics disputed.
  • Sampling and temperature (probabilities → a sentence): greedy takes the max; sampling is more diverse; divide scores by temperature T before softmax (low T sharper, high T flatter); top-k / top-p truncate the tail .
  • Context → logits → probabilities → sample → append.
  • One sentence trains many next-token questions; p from 5.4% to 99.8%.
  • One sentence (“the sky is blue”) practises 5 next-token predictions at once . This site’s model starts with the right token at only 5.4%; after 200 steps it is 99.8%.
  • Temperature : scores 4.1 / 1.3 / 1.0; T = 1 → 90% / 5.5% / 4.1%; T = 0.5 → 99.4% / 0.4% / 0.2%; T = 2 → 69% / 17% / 15%.
  • L = −(1/T) Σ log P(xₜ|x_<ₜ)
  • softmax(scores / T)
  • L = − (1/T) × Σ log P(x_t | x_1, …, x_(t−1))
  • Perplexity = e^L: roughly how many candidates it is torn between
