Evaluation

Benchmarks, perplexity, contamination, judges

▶ Open the interactive version (diagrams, labs, quizzes)

After training, how do we know how strong a model is?

Do not trust vibes — evaluate with fixed rulers.

  • Same exam for everyone.
  • Perplexity = hesitation, not usefulness.
  • Leaked exam = contamination.
  • Benchmarks: fixed sets (MMLU, GSM8K, HumanEval).
  • Perplexity e^L: how many candidates it is torn between — not the same as usefulness.
  • Contamination: test items in training inflate scores.
  • Human / model judges; agents also need task success and safety checks.
  • Benchmarks → scores; also human/model judges.
  • L=ln4 → perplexity 4; 8/10 → 80%.
  • L = ln 4 → perplexity 4.
  • A right, B wrong on one item → A gains; if the item was in A’s train set, distrust the score.
  • perplexity = e^L
  • accuracy = correct / total
  • perplexity = e^L
  • accuracy = correct / total
  • L: mean negative log-likelihood (loss)
  • perplexity: e^L, lower = less hesitation
  • accuracy: how many items are right

Left open We can measure. But the base model only continues text — post-training is next.
