Neural Network Basics

A neural network = many small “weighted sum + activation” parts, stacked in layers.

A neural network is many small “weighted sum + activation” parts stacked in layers; it learns by looping forward pass → loss → backprop → update, many times over.

Why it’s designed this way: Instead of writing rules, build a big adjustable function and let data set every knob; the chain rule finds the direction for billions of knobs in one pass. Why such trained networks generalize so well is still largely an empirical finding.

▶ Open the interactive version (tap the diagram, try labs, take the quiz)

🧒 In plain words

A neural network is built from lots of tiny parts. Each part does one thing: multiply a few numbers by how “important” each is, add them up, and pass the result through a “switch”. Stack thousands of these parts in layers and they can do very complicated things.

Its skill is practised: guess an answer, see how wrong it is, work out which way each knob should turn, turn it a little, and go again.
