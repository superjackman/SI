🔁 （训练模式）训练是怎么回事：损失 → 反向传播 → 更新参数

训练就是拿海量文本反复做“猜下一个词”的练习题：猜完对答案，错得越离谱“扣分”（损失）越多，然后把所有参数往“少扣分”的方向挪一点点。重复几十亿、上万亿次。

示例数据

题目：“今天天气真 ___”，原文的正确答案是 “好”。

损失 = −log(正确词的概率)：给正确答案 70% 时损失约 0.36；只给 10% 时损失约 2.3。

👀 看什么：绿色 = 整词命中；蓝色 = 拆成的子词片段；黄色 = 词表里没有，退回字节（一个汉字 3 个字节）。把“有趣”加进词表，token 数会变少——词表越大序列越短，但打分层也越大，这就是要权衡的地方。






🧪 接龙大师：你来选词，看温度 / top-k / top-p 怎么改概率 示例数据：编好的打分表


设计动机：模型每一步只给出“下一个词的概率表”，怎么从表里挑词是另一回事。总挑最高的会啰嗦重复，完全随机又会胡说；温度、top-k、top-p 就是在“稳”和“活”之间调旋钮。

















👀 试试：点任意一行亲手选词。把温度拉到 0.1，几乎只剩第一名（像“贪心”）；拉到 2.5，“香蕉”“量子”这类怪词也有机会。top-k=2 只留前两名；top-p=0.6 只留“累计概率到 60%”的那几个——灰色的行在采样时根本不可能被选中。















神经网络入门：从一个神经元到训练循环


大模型的每一个零件，都是由最简单的“加权求和 + 激活”搭起来的；它的本事，全靠同一个循环练出来：前向 → 损失 → 反向传播 → 更新。点方块看详情，下面的实验可以亲手调。








一句话记住每个零件




说明：这里讲的是原理。真实大模型的“神经元”就是这些，只是数量多到几十亿个参数，结构更讲究（注意力、残差、归一化）。






🧪 一个神经元：拖动权重看它怎么画线 示例数据


设计动机：神经元只是“加权投票 + 门槛 + 开关”。在二维平面上，它的输出等于 0.5 的地方是一条直线：权重决定直线的方向，偏置决定它平移到哪里。


















👀 试试：把 w₂ 拖到 0，直线变成竖的（只看 x₁）；改偏置，直线平移；换成阶跃，边界变得生硬（没有“有多确定”）。无论怎么调都只能是一条直线——想分开“异或”这种图案，必须用多个神经元组成网络（见下面的“小网络”实验）。






🧪 激活函数对比：形状、斜率与梯度消失


设计动机：没有弯折，叠多少层都只等于一层（线性套线性还是线性）。但弯折的斜率又决定梯度能不能传回去：反向传播时每层都要乘一次斜率，斜率小于 1 的层叠多了，梯度就消失。














为什么必须有非线性？







👀 试试：选 Sigmoid，把层数拉到 20：梯度剩下不到百万分之一，前面的层几乎学不动。换成 ReLU（输入为正时）梯度一直是 1。勾选“去掉激活”：6 个神经元叠两层，画出来仍是一条直线。






🧪 反向传播一步一步算：计算图与链式法则 示例数据


设计动机：每个节点只需要知道自己的局部导数。从损失往回走，每到一个节点就把“上游传来的梯度”乘上本地导数再交给前一个节点——这就是链式法则，所有参数的梯度一次反向全部算完。















👀 试试：一直点“下一步”：先前向算出 z、a、L，再反向得到 ∂L/∂w、∂L/∂b，最后更新。连续走几圈，看损失一圈比一圈小。把 w 调到 2、x 调到 2：z 很大、σ′ 几乎为 0，梯度几乎消失（Sigmoid 饱和）。






🧪 梯度下降下山：SGD / 动量 / Adam 与学习率 玩具地形


设计动机：梯度只告诉你脚下哪边最陡，不告诉你该走多远。狭长山谷里纯 SGD 会左右乱晃；动量靠惯性把来回抵消；Adam 再按每个方向的坡度自动调步长。学习率太大就会越过谷底、甚至越跳越高。


















👀 试试：先点“合适”再播放：SGD 在山谷里来回晃，动量冲得快，Adam 走得最直。点“太小”：几乎不动；“太大”：震荡；“发散”：飞出地图。换成“两个坑”，点图上不同位置当起点：从右边出发常常卡在浅坑里——梯度下降只能看见脚下。






数据怎么喂：小批量与训练 / 验证 / 测试






一轮（epoch）= 把训练集按小批量全部用一遍。每个小批量算一次平均梯度、更新一次参数。验证集只看不学，用来挑设置和决定何时停；测试集最后只考一次。


大模型的数据多到通常只过一轮左右，所以“背题”的风险和小模型不同；但评测题混进训练数据（数据污染）仍会让分数虚高。






初始化与归一化：让信号层层都“音量合适”




权重太大，信号每过一层就放大，几十层后爆炸；太小又会层层衰减到零。初始化按层宽缩放起点，归一化在训练全程每层再校准一次。








🧪 训练一个小网络：决策边界、过拟合与早停 示例数据：随机生成的二维点


设计动机：一个神经元只能画直线；一层隐藏神经元各画一条线，输出层把它们拼起来，就能弯出任意形状的边界。可是神经元太多、数据太少，它会连噪声一起背下来——训练误差一直降，没见过的测试点却越错越多。
















👀 试试：选“异或”、隐藏神经元 1 → 只能一条直线，学不会；调到 4 → 学会了。点“过拟合示范”（数据少、噪声大、16 个神经元）训练很久：实心训练点几乎全对，空心测试点错得越来越多，下图紫线标出验证最好的时刻——这就是早停的时机。再把 L2 设为 0.01 或打开 dropout，边界会变平滑。






正则化：别死记硬背




常用的四招：L2 权重衰减（偏好小权重）、dropout（随机关掉神经元）、早停（验证集变差就停）、更多 / 增强的数据。它们都在给“更简单、更平滑的解释”加分；哪招最有效，多半要靠实验。








卷积网络（CNN）：给图片用的神经网络




全连接层把每个像素都连到每个神经元，一张 1000×1000 的图光第一层就要上亿个权重。卷积只用一个 3×3 的小窗口在图上滑动、到处复用同一组权重：参数少几个数量级，而且“猫耳朵出现在左上还是右下”都能认出来。








循环网络（RNN / LSTM）：为什么被 Transformer 取代




RNN 一个词一个词地读，把读过的内容压进同一个“记忆”向量；LSTM 加上门和“记忆传送带”，能记得更久。


    

  • 并行：RNN 第 100 个词要等前 99 个算完；Transformer 一次把所有词一起算，GPU 能吃满，训练快得多。
    • 

  • 长距离：RNN 里第 1 个词要经过 99 步才传到第 100 个，信息和梯度一路衰减；注意力让任意两个词一步直达。
    • 

  • 不挤在一个向量里：注意力可以回头看每个词的原始向量，不用把整段话压缩成一个固定长度的记忆。
    • 



代价：注意力的计算量随长度的平方增长，所以长文本又催生了线性注意力、状态空间模型等“带记忆”的新设计——RNN 的思路并没有完全消失。






🧪 词向量空间：近义词与类比 玩具数据：手工摆放的二维示意


设计动机：训练让“出现在相似上下文里的词”向量靠近，于是“相似”变成了“距离近”，某些“关系”变成了“方向”。真实词向量有几百到几千维，这里用二维示意；坐标是为演示摆放的，不是真实模型的输出。














👀 试试：点图上任意一个词，看离它最近的三个邻居。再试三个类比预设：箭头 A − B + C 落在哪个词附近。真实模型里类比只是“大致成立”，还会学到数据里的偏见。






时间线：神经网络 80 年




很多关键想法几十年前就有了；2012 年以后爆发，主要靠三样东西同时到位：大数据、GPU 算力、以及让深网络能训练起来的技巧（ReLU、好的初始化、归一化、残差）。














Transformer 块内部：




放大一个 Transformer 块


大模型中间是很多个一模一样结构的“块”叠在一起（真实模型常见几十层）。每个块里只有两个主要工序：注意力（词与词交流）和前馈网络（每个词自己消化），每个工序后面跟着残差 + 归一化。










一句话记住每个零件




小知识：2017 年原始论文是“先计算，再残差+归一化”；现在很多模型改成“先归一化，再进注意力/前馈，最后加残差”（叫 Pre-Norm），训练更稳定。零件还是这些，只是顺序微调。






打个比方：一群人一起读句子


把每个词想成一个人。注意力 = 开个短会，每个人去听听前面相关的人在说什么；前馈网络 = 散会后各自回座位，结合自己的“知识库”想一想；残差 = 想法是在原稿上写批注，原稿一直保留；归一化 = 每轮讨论后把音量调到统一大小，免得有人越喊越响。这样的“开会 + 消化”重复几十轮，每个人对整句话的理解越来越深。

🧪 动手实验室：Transformer 块




🧪 自己搭一个 Transformer 块：开关残差 / 归一化 / 前馈，叠很多层看看 简化模拟：16 维随机小网络，不是真模型


设计动机：块要叠几十层。每层都把数字乘一乘，叠多了就会“越乘越大（爆炸）”或“越乘越小（消失）”，前面的层就学不动。残差给了一条直通路，归一化把尺度拉回来——它们不是为了“更聪明”，而是为了“叠得深还能训练”。






















👀 试试：①全开：信号和梯度都比较平稳。②关掉归一化：有残差时数字一层层累加，越来越大。③关掉残差、留着归一化：前向被拉平了，但梯度一层层传回去会衰减或放大。④两个都关、把初始化尺度调到 0.7 或 1.4：很快消失或爆炸。⑤关掉前馈网络：信号看着正常，但块里少了“消化”这一步，能学到的东西少了一大半（这一点这里的曲线看不出来）。













Transformer 块内部：




注意力内部：每个词怎么决定“该看谁”


每个词都准备三张卡：提问卡 Q（我在找什么）、标签卡 K（我是什么，供别人匹配）、内容卡 V（被关注时我交出的信息）。就像在图书馆：你拿着问题（Q）去对照每本书的书脊标签（K），越对得上越认真看那本书的内容（V）。










🧪 动手看：点一个词，看它在“看”谁 示例数据：编造的小数字，每张卡只有 2 个数


句子：“我 爱 吃 苹果”。真实模型每张卡有几十到上百个数字，这里只用 2 个，方便手算。

















关注热力图 （行 = 谁在看，列 = 被看的词；颜色越深看得越多；点格子切换行）







展开看一步步的计算



打分 = Q 和 K 对应位置相乘再相加（点积），再除以 √2（2 是卡片长度）。遮挡 = 把“后面的词”的分数设成负无穷，softmax 后就是 0%。








多头：好几组人同时用不同的眼光看


一组 Q/K/V 表只能学会一种“看法”。所以注意力里有很多组（“多头”，常见几十个），每组用自己的 Q/K/V 表独立走完上面 ①~④ 的流程，最后把各组结果首尾拼起来，再乘一张输出表整合成原来的长度。人们常把不同的头比作“有的盯语法、有的盯指代（‘它’指谁）、有的盯相邻词”——但这只是比喻，具体分工是训练中自然形成的，很多头并不好解释。






🧠 底层逻辑：Q/K/V、打分、遮挡、多头为什么这样设计、为什么有效


一句话版本：Q/K/V 三种角色（我在找什么 / 我怎么被找到 / 我交出什么）→ Q·K 点积当相关度 → ÷√长度防止比例太极端 → 遮挡不许偷看答案 → softmax变成总和固定的比例 → 按比例混合 V → 多头同时用几种眼光看。

🧪 注意力游乐场：换词、开关遮挡、改头数 示例数据：注意力模式是按规则编的


设计动机：一个词的意思要靠上下文决定（“它”指谁？）。注意力让每个词按“相关程度”去混合别的词的信息；遮挡保证不偷看后文；多个头让模型同时用几种眼光看。

Transformer 块内部：




前馈网络：每个词自己“消化”


两张大表夹一个“过滤开关”：先把向量放大成更长的一串（常见约 4 倍长），每个数像一个“特征探测器”；开关只让有用的探测器亮着；第二张表再把亮着的信号汇总、压回原长度。







🧪 小演示 示例数据：输入 3 个数 → 放大到 12 个 → 缩回 3 个










为什么一定要“过滤开关”？如果没有它，两张表连着乘，数学上等于一张表，叠再多层也只能做“简单的线性变换”。有了开关，模型才能表达“如果……就……”这类复杂规律。现在常用比 ReLU 更平滑的开关（如 GELU、SwiGLU；SwiGLU 还会多用一张表）。


很多研究认为，模型记住的大量“知识”（比如“巴黎是法国的首都”）主要存放在前馈网络这两张大表里。














➕ 残差：原稿保留，只加批注


残差连接 点我看详情
每个工序算出的结果不是替换原向量，而是加到原向量上。




好处：信息不会在几十层里“传丢”；训练时调整信号也能顺着这条“直通道”传回前面的层。








📏 归一化：把数字调到统一尺度


归一化 点我看详情
不管数字原来多大多小，都调整成“平均 0 左右、波动差不多”。




上面演示的是经典的 LayerNorm；现在多数大模型用 RMSNorm：不减平均值、只把整体大小拉齐，更省，效果基本一样。










输出打分层 + softmax：从向量到“下一个词的概率”


走完所有层之后，拿最后一个位置的向量，和打分表里每个词的那一行比一比，得到每个词一个分数；softmax 再把分数换算成加起来 100% 的概率。












🤔 嵌入表和输出打分表是同一个东西吗？


长得一样，干的活相反。默认是两张独立的表，但也可以让它们共用一张。




词嵌入表（入口）输出打分表（出口）


形状完全一样：词数 × 向量长度（词表里每个词一行，每行几千个数）


方向编号 → 向量（查表，取出一行）向量 → 每个词一个得分（和每一行做点积）


回答的问题“这个词是什么意思？”“什么样的上下文后面该接这个词？”


默认两套独立参数，各自训练






🔗 共用（“权重绑定”）：输出打分表直接用嵌入表的转置（把同一张表“倒过来用”）。
好处：① 参数更少（省下一整张“词数×长度”的大表）；② 读进来和写出去用同一套坐标系，一个词的“意思”和“该不该输出它”天然对齐。小模型里常常效果不错。


✂️ 分开（不绑定）：入口要的是“这个词是什么意思”，出口要的是“什么上下文后面跟这个词”，两件事不完全一样，分开更灵活。对大模型来说，多出这一张表占总参数的比例很小，代价不大，所以不少大模型选择分开。




如果分开了，两张表里同一个词的数字不一样，会出问题吗？ 不会。每张表各自拿到自己的训练信号：嵌入表那一行根据“这个词作为输入时该提供什么信息”来调整；打分表那一行根据“这个词作为答案时该和什么样的上下文向量对齐”来调整。中间几十层会学会在两套“坐标”之间翻译。
如果共用了，这两种训练信号会加在同一张表上，同时满足两种角色。


⚠️ 局限/说明：绑定还是不绑定没有绝对的对错，哪种更好要看模型规模和实验结果。






🎯 为什么最后一个位置的向量和打分表各行做点积就能选出下一个词






① 最后的向量 h 是什么？ 经过所有层后，“真”这个位置的向量 h 浓缩了“读完整句话后，我想接什么”。


② 点积在量什么？ 两串数对应相乘再相加。两个箭头方向越一致，点积越大；方向相反就是负数。


③ 这个“一致”本来没有意义，是训练让它有了意义。 一开始 h 和各行都是随机的，点积高低纯属巧合。每次训练：梯度把正确词那一行往 h 的方向拉，同时把 h 往正确词那一行的方向拉（h 是被前面所有层的参数间接拉动的）；那些被高估的错误词则被往反方向推。练上亿次后，“读到这种上下文”的 h 就会和“该接的词”那一行方向一致。


④ 推多少？ softmax + 交叉熵的梯度极其简单：每个词分数的调整量 = 预测概率 − 正确答案（正确词是 1，其他是 0）。正确词只给了 30%，就被往上推 0.7 份；错误词拿了 50%，就被往下压 0.5 份。


⑤ 为什么偏偏选点积 + softmax？ 简单；一次矩阵乘法就能给几万个词同时打分，非常适合 GPU 并行；梯度稳定、好训练。它不是唯一可能的设计，只是又简单又好用。

🧪 显存计算器：权重 + KV 缓存装得下吗？ 示例配置，不对应任何具体模型


设计动机：生成时每写一个词都要回看前文。把前文每层的 K、V 存起来就不用重算——代价是要占显存，而且随“上下文长度 × 并发人数”线性增长。分组查询（GQA）、量化缓存都是为了压它。























🧪 量化滑块：每个数用几位？ 示例数据：64 个随机权重


设计动机：模型的数字大多挤在 0 附近，不需要很高精度。把 16 位的数变成 8 位、4 位，模型体积成倍缩小、搬运更快；代价是“格子变粗”带来误差。分组量化让每一小组用自己的刻度，减轻个别大数（离群值）的拖累。












👀 看什么：灰点 = 原始值，彩色线 = 量化后还原的值。位数越少，台阶越粗。勾上离群值、不分组时，整把尺子被一个大数撑开，小数几乎全被压成 0；打开分组就好很多。“质量影响”是经验示意，真实影响取决于模型和方法。

“规模规律”（模型、数据、算力越大效果越好）是大量实验总结的经验趋势，会遇到收益递减，也不是物理定律。


🧪 动手实验室：训练




🧪 学习率与过拟合：拟合一条曲线 示例数据：10 个训练点 + 40 个验证点


设计动机：训练就是“沿着误差下降的方向小步走”。步子（学习率）太小走不动，太大会越过谷底甚至飞出去；模型太简单学不会规律（欠拟合），太复杂会把噪声也背下来（过拟合）。所以要留一份“没见过的题”（验证集）来检查。















👀 试试：次数 1 → 欠拟合（直线拟合不了弯曲）；次数 3~4 → 刚好；次数 9 + 训练很久 → 过拟合（曲线穿过每个蓝点，但橙色验证误差反而上升）。学习率拉到最右 → 发散。过拟合时把权重衰减设成 0.01 看看。






🧪 强化学习迷宫：你来摆墙、陷阱和奖励 Q-learning，7×7 小格子


设计动机：很多事没有“标准答案”可以模仿，只能“做了才知道好不好”。强化学习让智能体反复试错，把“终点的好消息”一格格往回传；但它只认奖励——奖励设计有漏洞，它就会钻空子。















👀 试试：先训练 500 回合，看箭头怎么指向宝藏；放一堵墙挡路，再训练，看它绕路。放一块 🍪（+1，不结束，吃完还会再长）在起点附近：它可能宁可在饼干旁边来回刷分也不去宝藏——这就是“奖励投机”，所以奖励要设计得和真实目标一致。
